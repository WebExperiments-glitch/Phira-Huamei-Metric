# 竞品调研：phibot.dev（2026-10-18）

一句话结论：**phibot.dev 不是 P.H.M. 的竞品，两者在互不相交的维度上。**
它甚至对 P.H.M. 构成正向依赖 —— 它的 RKS / B30 数据来源是 Phigros 官方存档，
而它的定数来自 Phigros 谱面里的官方标度，不是 P.H.M. 算出来的。

---

## 一、phibot.dev 到底是什么

用 TapTap / Discord 登录，主打「打开就是你的 B30」。

| 类别 | 功能 | 登录 |
|---|---|---|
| **要登录** | B30（Best 30 + 3 个 Phi 位）、历史成绩与 RKS 趋势、个人名片 | TapTap / Discord |
| | x30（1-Good 算进去）、fc30（全连榜） | 同上 |
| | 单曲 ACC 在 phib19.top 记录中的排名位置 | 同上 |
| | 谱面标签含义解释（tag profile） | 同上 |
| | **Simulation** —「假设你某首多打了几分，RKS 会变成多少」 | 同上 |
| **免登录** | 歌曲搜索（支持玩家昵称，如「无限光」「ASA」） | — |
| | **Phira packs** — 把任意谱面打成 .pez 包，可回溯到 1.2.0、愚人节、已下架曲、Legacy | — |
| | Score control — 反推「Perfect/Good/Bad/Miss 各多少能正好凑到目标分」 | — |
| | 曲绘 / 音乐 / 谱面包 / chart JSON 浏览与下载 | — |
| | PV（章节与活动 PV，带游戏内叠加层，可逐帧 Deduction） | — |
| | Collection — 图鉴条目与线索，按章节、五种语言、可搜索 | — |

输出形态很明确：三种版式的**图片**（Classic 卡片 / Table / Phone 窄卡），一张图发朋友圈用。
还能进Discord 用 `/b30`。

## 二、为什么不构成竞争

| 维度 | PhiBot | P.H.M. |
|---|---|---|
| **回答的问题** | 「**我**打得怎么样？」 | 「**这首**难不难、难在哪？」 |
| **输入** | TapTap/Discord 账号绑定 | 一个 `.pez` 谱面包 / chart_id |
| **输出** | RKS / B30 / 排名 —— 关于**人** | 定数 + 官谱参照 + 四项技能 —— 关于**谱** |
| **数据来源** | Phigros 官方存档（成绩是真的） | 谱面文件本身（算出来的） |
| **定数从哪来** | 谱面 JSON 里**官方写死的** Level | P.H.M. **自己算**的 8 维 k-NN |
| **要不要登录** | 大部分功能要（Discord OAuth） | 匿名拖进去就能用 |
| **形态** | 社交向、图分享 | 工具向、查完就走 |

关键一点：**PhiBot 自己不算定数**，它只是把谱面里已有的官方 Level 显示出来。
所以「定数算得准不准」这个 P.H.M. 真正在做的事，它根本没有触碰到。

两边其实可以互补：PhiBot 说「你在 15.3 这首上 ACC 92%」，
P.H.M. 说「15.3 这首的难点在 88 分处的 12 连纵列」。

## 三、真正值得注意的地方（不是竞争，是信号）

1. **它开源了。** 主页有 Discord bot 源码入口。而 P.H.M. 仓库其实**早就是 public + GPL-3.0**，
   只是描述停在 V0.3.2、没挂 homepage、没打 topic —— 等于「开着门但没人知道」。
   已补齐元数据。

2. **它的短板恰好是 P.H.M. 的长板。**
   - 没有「这首为什么难」的拆解 → P.H.M. 的技能分离正对这块
   - 必须登录才能看到自己的东西 → P.H.M. 匿名可用
   - 只给 RKS 一个数 → P.H.M. 给参照 + 技能 + 为什么

3. **⚠ 它的 Simulation 功能值得盯。**
   「假设某首 ACC 提升到 x%，RKS 会变成多少」= 「改动谱面会怎样」。
   如果它把这个思路扩到**自制谱**（改定数会怎样、删掉一段会怎样），
   那才真的碰到 P.H.M. 的地盘。目前没有。

4. **它甚至在帮 P.H.M. 导流。** `/b30` 的结果是玩家卡图片，玩家为了生成图会来查分，
   查到分数就会问「这歌到底难在哪」—— 那是 P.H.M. 的入口。

---

## 四、结论与动作

- **不紧张。** 维度不重叠，且它在成绩侧、数据来自官方，我们不与之争。
- **开源不是「因为对方闭源」才做**：我们仓库本来就是 public + GPL-3.0。
  真正欠的是**门面**—— 补了描述、homepage、8 个 topic。
- **差异化主线**：坚持「**可审计 + 不给判决**」。PhiBot 是黑盒展示，
  P.H.M. 是能说出每个数字怎么来的。这条护城河比任何功能都值钱。
