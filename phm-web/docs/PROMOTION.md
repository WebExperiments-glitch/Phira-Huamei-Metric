# 宣发手册

> 这份文件只干一件事：**把「怎么发」写成能照着做的步骤，附可直接复制粘贴的文案。**
> 写它是因为「临场憋文案」是宣发最容易卡住的地方。

---

## 0. 先认清各平台的差异（决定了打法，不是文案）

| 平台 | 链接能点吗 | 有卡片预览吗 | 所以必须 |
|---|---|---|---|
| **QQ 频道 / 群** | 能，但陌生域名**容易被折叠** | 有（og 卡片） | 用**图**说话，链接放简介 |
| **抖音** | **基本点不了** | 无 | 画面里带域名，引导搜索 |
| **B站** | 简介能点（有风控） | 动态能点 | 视频 / 专栏打长尾 |
| **X** | **能点，还有大图卡片** | 有（og-en.png） | 唯一能直接发链接的，但要用英文 |

⚠️ **一个必须先说的现实**：Phira 的玩家绝大多数在中国。
X 上的触达会很小 —— 它的作用是「有个国际门面 + 英文入口」，**不是主战场**。
真正的人在国内。所以：**X 当作练手**（没人认识你，发砸了也没关系），
**QQ 才是真战场**。

## 1. X：一步步来

### 1.1 发之前
- [ ] 账号能正常发帖（新号带外链容易被限流 → 先随便发 1~2 条不带链接的）
- [ ] 打开 https://phm.app.workbuddy.host/en.html 确认能打开、卡片图正常

### 1.2 帖子内容（直接复制）

**主推文案：**

```
I built a difficulty reference for Phira charts.

It pulls structural features out of a chart pack and places it against
1,037 official charts — you get a number on the official scale, plus the
uncertainty range of that number.

Runs entirely in your browser. Charts are never uploaded.

https://phm.app.workbuddy.host/en.html

#Phigros #Phira #rhythmgame
```

**备选（更"钩子"一些）：**

```
Chart difficulty ratings are black boxes. So I made one that shows its work.

Drop a Phira chart pack → 1,037 official charts, k-nearest-neighbour,
one number + how uncertain it is. Nothing is uploaded.

https://phm.app.workbuddy.host/en.html

#Phigros #Phira #rhythmgame
```

### 1.3 发的动作
1. 把上面的文案粘进发帖框
2. **文字发出去前先看一眼链接下面有没有出现大图卡片**（X 会自动抓 `og-en.png`）。
   如果没出现 → 手动把 `og-en.png` 作为图片附上（自动卡片偶尔不渲染）
3. 发完后**把这条推置顶**（个人主页 → 该推 → Pin to profile）
4. 时间选**北京时间 21:00–24:00**（对应欧洲下午、美东上午，覆盖面最好）

### 1.4 发完之后
- **别 @ 任何人**（会被判定 spam）
- **一条推只放一个链接**
- 有人回复就认真回 —— 一条没人回的推等于白发
- 隔几天可以发第二条：挑一张有代表性的谱，贴它的分享卡片图（不带链接也行）

## 2. QQ：怎么宣发才不被折叠 / 不被踢

### 2.1 落点（按安全性排序）

| 去处 | 入口 | 评价 |
|---|---|---|
| **Phira 官方 QQ 频道** | `pd.qq.com/s/ezgv3q71g` | ✅ **首选**。频道发帖不像群里那样被人盯着，心理压力小 |
| 官方 4 群 | `685895528`（1~3 群已满） | ⚠️ 群里一上来发链接容易被当广告 |
| 各种玩家群 | 各群自找 | ⚠️ **千万不要同一段话群发多个群** |

### 2.2 铁律（踩了就是被折叠/被踢）

1. **进群先别发东西。** 先聊两天、回答几个问题，让人知道你是谁。
2. **正文不带链接。** 用**图**（分享卡片）代替。链接放频道简介 / 置顶 / 群公告。
   > QQ 对陌生域名的处理是：**折叠成灰色不可点**，或者干脆不显示。
   > 正文写「P.H.M. Standard，搜一下就有」比直链稳得多。
3. **不要群发。** 同一段文字发到多个群 = 广告，会被踢。
   想扩大范围就找人**转发**，别自己刷。
4. **姿态放低**：写「欢迎来打脸，算错了告诉我」，不要写「我做了个牛逼工具」。

### 2.3 帖子内容（直接复制）

```
做了个小工具，想请大家帮忙看看有没有算歪的地方

【P.H.M. Standard】给 Phira 谱面算一个结构难度参考

把谱面包拖进去（或者搜曲名点「算」），它会把这张谱的 5 个结构特征
和 1037 张官谱做 k-NN，给出一个跟官谱同标度的参考定数
—— 并且给出这个数的不确定范围。

几点说明：
· 不判定「虚标」。只给数字，以及这个数字有多准。
· 谱面文件不会上传，全部在你的浏览器里解析。
· 结论能点开看依据：匹配到了哪 20 张官谱、每张多少定数。
· 库里数据还不多，欢迎来打脸 —— 算得不对请直接告诉我。

工具在这：phm.app.workbuddy.host（搜「P.H.M. Standard」也行）
```

**配图**（两个选择，都不用现做）：
- **工具介绍图** → `phm-web/public/og.png`（就是链接分享时那张卡片）
- **某张谱的体检卡** → 页面上「算」完 → 导出横版图

图比链接有效得多，而且图上自带域名。

### 2.4 扩大战果（不刷屏的做法）
- 找 **2~3 个活跃的谱师 / 玩家**，私聊一句：「做了个东西，能不能帮我看一眼有没有问题」
  —— 被挑出问题反而是好事，改完再发就是「有反馈的版本」
- 有人反馈算得不准 → **别辩解，记下来**。改完单独回复他：「按你说的看了，确实是……已修」
  —— 这一步做扎实，比发十条帖都管用

## 3. B站 / 抖音（后面再说）

- **B站**：长尾最长，值得优先投入。视频（方法论）+ 专栏（讲清楚）+ 动态（短更新）
- **抖音**：链接点不了，必须用**竖版卡片**（页面里可以导出）+ 画面里带域名
- ⚠️ 两个平台都别用「虚标」两个字，说「标称 X，实测 Y，偏差 Z」

---

## 4. 避雷清单（发之前扫一眼）

- [ ] 有没有用「虚标」这个词？→ 改成「偏差」
- [ ] 有没有做「定数排行榜 / 战力榜」？→ 会变骂战，别做
- [ ] 有没有暗示这是「官方定数」？→ 立刻改
- [ ] 有没有一条消息里塞多个链接？→ 拆开
- [ ] 有没有在多个群发同样的话？→ 停
- [ ] 有没有 @ 一堆人？→ 删掉

---

## 5. 最后一件事：**推广前先自己用一遍**

发出去之前，自己走一遍完整流程：
搜一张谱 → 点算 → 看卡片 → 导出分享图 → 发给朋友看看。

如果自己都觉得「这个提示看不懂」「这个按钮找不到」，
外面的人只会更懵。**产品本身就是最好的宣发。**
