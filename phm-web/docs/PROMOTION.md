# 宣发手册

> 这份文件只干一件事：**把「怎么发」写成能照着做的步骤，附可直接复制粘贴的文案。**
> 写它是因为「临场憋文案」是宣发最容易卡住的地方。

---

## 0. 先认清各平台的差异（决定了打法，不是文案）

| 平台 | 链接能点吗 | 有卡片预览吗 | 所以必须 |
|---|---|---|---|
| **QQ 频道 / 群** | 能，但陌生域名**容易被折叠** | 有（og 卡片） | 用**图**说话，链接放简介 |
| **抖音** | **基本点不了** | 无 | 画面里带域名，引导搜索 |
| **B站** | 简介能点（有风控） | 动态能点 | 视频 / 专栏打长尾 |
| **X** | **能点，还有大图卡片** | 有（og-en.png） | 唯一能直接发链接的，但要用英文 |

⚠️ **一个必须先说的现实**：Phira 的玩家绝大多数在中国。
X 上的触达会很小 —— 它的作用是「有个国际门面 + 英文入口」，**不是主战场**。
真正的人在国内。所以：**X 当作练手**（没人认识你，发砸了也没关系），
**QQ 才是真战场**。

## 1. X：一步步来

### 1.1 发之前
- [ ] 账号能正常发帖（新号带外链容易被限流 → 先随便发 1~2 条不带链接的）
- [ ] 打开 https://phm.app.workbuddy.host/en.html 确认能打开、卡片图正常

### 1.2 帖子内容（直接复制）

**主推文案：**

```
I built a difficulty reference for Phira charts.

It pulls structural features out of a chart pack and places it against
1,037 official charts — you get a number on the official scale, plus the
uncertainty range of that number.

Runs entirely in your browser. Charts are never uploaded.

https://phm.app.workbuddy.host/en.html

#Phigros #Phira #rhythmgame
```

**备选（更"钩子"一些）：**

```
Chart difficulty ratings are black boxes. So I made one that shows its work.

Drop a Phira chart pack → 1,037 official charts, k-nearest-neighbour,
one number + how uncertain it is. Nothing is uploaded.

https://phm.app.workbuddy.host/en.html

#Phigros #Phira #rhythmgame
```

### 1.3 发的动作
1. 把上面的文案粘进发帖框
2. **文字发出去前先看一眼链接下面有没有出现大图卡片**（X 会自动抓 `og-en.png`）。
   如果没出现 → 手动把 `og-en.png` 作为图片附上（自动卡片偶尔不渲染）
3. 发完后**把这条推置顶**（个人主页 → 该推 → Pin to profile）
4. 时间选**北京时间 21:00–24:00**（对应欧洲下午、美东上午，覆盖面最好）

### 1.4 发完之后
- **别 @ 任何人**（会被判定 spam）
- **一条推只放一个链接**
- 有人回复就认真回 —— 一条没人回的推等于白发
- 隔几天可以发第二条：挑一张有代表性的谱，贴它的分享卡片图（不带链接也行）

## 2. QQ：怎么宣发才不被折叠 / 不被踢

### 2.1 落点（按安全性排序）

| 去处 | 入口 | 评价 |
|---|---|---|
| **Phira 官方 QQ 频道** | `pd.qq.com/s/ezgv3q71g` | ✅ **首选**。频道发帖不像群里那样被人盯着，心理压力小 |
| 官方 4 群 | `685895528`（1~3 群已满） | ⚠️ 群里一上来发链接容易被当广告 |
| 各种玩家群 | 各群自找 | ⚠️ **千万不要同一段话群发多个群** |

### 2.1.1 频道里发到哪个子频道？—— **别选灌水**

**灌水区别去。** 三个理由：
1. 灌水区是**聊天流**，消息几小时就被冲走，没人会回头翻
2. 版主对灌水区的广告**最敏感** —— 发工具贴等于自己给自己贴「广告」标签
3. 即使没被删，定位也不对：那里的人是来闲聊的，不是来找工具的

**按这个顺序找子频道：**

| 优先级 | 找什么 | 为什么 |
|---|---|---|
| 1 | 名字带 **工具 / 资源 / 创作 / 分享 / 作品** 的**帖子型**频道 | 来的人本来就在找这类东西 |
| 2 | **综合 / 日常** 类 | 次优，但要发**帖子**（不是聊天消息） |
| 3 | 只有灌水区 | **先别发**。私聊频道主问一句「有没有能放工具的子频道」 |
| 4 | 频道主不回 | 去官方 4 群，按 §2.2 的铁律来 |

**怎么区分「帖子型」和「聊天型」**：进去看有没有「发帖」按钮、有没有帖子列表
（标题 + 回复数）。聊天型只有一条条消息流。

> **一定要发成帖子，不要发成聊天消息。** 帖子有标题、能被翻到、能置顶；
> 聊天消息几分钟就沉底了。

### 2.1.2 标题写什么（挑一条，别自己现编）

1. `做了个算 Phira 谱面定数的工具，想请大家帮忙看看`
2. `【工具】Phira 谱面难度参考 —— 给一张谱一个数，以及这个数有多准`
3. `做了个小工具：拖入谱面包就能算结构定数（结论能点开看依据）`
4. `想请大佬们帮忙验一下这个谱面定数工具（欢迎打脸）`

> 三条原则：**不吹**（别写"革命性""最准"）、**说清是什么**（"算定数"而不是"AI 分析"）、
> **留下台阶**（"帮忙看看"比"快来用"好得多）。

### 2.1.3 正文（直接复制）

> ⚠ **V0.4.0 起改成双标度叙述**（见下面「怎么回答"我的 IN 14 被算成 11.6"」）。
> 别再用「和官谱同标度」这个说法 —— 现在主结果是**社区共识**标度，
> 官谱标度作为第二栏并列给出。

```
把谱面包拖进去（或者搜曲名点「算」），它会算出这张谱的 8 个结构特征，
拿去和 9508 张社区谱做 k-NN，给出两个数：
· 社区共识 —— 站内同类谱实际被定到多少（谱师会拿这个对照）
· 官谱标度 —— 换成 1037 张 Phigros 官谱时的对应值
外加不确定范围（比如 15.7，范围 14.2–17.1）。

几点说明：
· 不判定「虚标」，只给数字，以及这个数字有多准
· 谱面文件不会上传，全部在你的浏览器里解析
· 结论能点开看依据：匹配到了哪 20 张谱、每张多少定数、什么名字
· 库里数据还不算多，算得不对请直接告诉我

phm.app.workbuddy.host
```

### 2.1.4 怎么回答「我的 IN 14 被算成 11.6」

这是最可能被截图发出来的一句话，**提前准备好答案**。它其实不是错误，是标度不同：

| 情形 | 正确的回答 |
|---|---|
| 两个标度差得多 | 「社区谱和官谱**结构分布本来就不一样**（社区谱定数中位 15.1、官谱 10.6；社区谱长条占比只有官谱的 1/3）。你看到的是两个尺子的差异，不是某个尺子算错了。页面上两个数都印着。」 |
| 不确定范围很宽 | 「你看范围是 9.5–14.5 —— 上限就贴着 14。跨度这么大说明这张谱的结构在参照集里没有紧密对应物，中点不该被当成结论。所以我把范围一起印出来了。」 |
| 邻居名字不认同 | 「那 20 张你可以点开看，名字都在。如果你觉得某张不该算进来，这正是我想要的反馈 —— 告诉我该换掉哪张。」 |
| 就是想骂 | 「收下。能说一句你直觉这谱该是多少、以及为什么吗？我好回去比。」 |

**一条底线**：绝不说「工具不会错」或「官方也是这么标」。
能说清楚的只有「这个数是怎么来的、以及它有多准」。

**发的动作：**
1. **图放第一张当封面** —— 用 `public/og.png`（工具介绍卡），或任意一张谱的导出卡片
2. 链接写成 `phm.app.workbuddy.host` —— **不要带 `https://`**，带协议头更容易被折叠
3. 发完**自己在下面回一楼**：「算得不对的请直接说，我改」—— 这比正文里写十句都管用

### 2.2 铁律（踩了就是被折叠 / 被踢）

1. **进群先别发东西。** 先聊两天、回答几个问题，让人知道你是谁。
2. **链接别带协议头。** 写 `phm.app.workbuddy.host`，不要写 `https://...`。
   > QQ 对陌生域名的处理是**折叠成灰色不可点**，甚至不显示；带协议头更容易触发。
   > 正文里再补一句「搜 P.H.M. Standard 也行」，比只放链接稳得多。
3. **不要群发。** 同一段文字发到多个群 = 广告，会被踢。
   想扩大范围就找人**转发**，别自己刷。
4. **姿态放低。** 写「帮忙看看算得对不对」，不要写「我做了个牛逼工具」。

### 2.3 扩大战果（不刷屏的做法）
- 找 **2~3 个活跃的谱师 / 玩家**，私聊一句：「做了个东西，能不能帮我看一眼有没有问题」
  —— 被挑出问题反而是好事，改完再发就是「有反馈的版本」
- 有人反馈算得不准 → **别辩解，记下来**。改完单独回复他：「按你说的看了，确实是……已修」
  —— 这一步做扎实，比发十条帖都管用
- 隔几天发第二条：这时可以带一张**具体谱的体检卡** + 一句「这张的偏差有点意思」，
  比重复介绍工具有效得多

## 3. B站 / 抖音（后面再说）

- **B站**：长尾最长，值得优先投入。视频（方法论）+ 专栏（讲清楚）+ 动态（短更新）
- **抖音**：链接点不了，必须用**竖版卡片**（页面里可以导出）+ 画面里带域名
- ⚠️ 两个平台都别用「虚标」两个字，说「标称 X，实测 Y，偏差 Z」

## 4. 避雷清单（发之前扫一眼）

- [ ] 有没有用「虚标」这个词？→ 改成「偏差」
- [ ] 有没有做「定数排行榜 / 战力榜」？→ 会变骂战，别做
- [ ] 有没有暗示这是「官方定数」？→ 立刻改
- [ ] 有没有说「和官谱同标度」？→ V0.4.0 之后主结果是**社区共识**标度，
      改成「社区共识 + 官谱标度两个都印」
- [ ] 有没有把「社区共识」说成「客观真值」？→ 它是**谱师声明的共识**，
      不是客观测量。说成客观真值一定会在群里被拆
- [ ] 有没有一条消息里塞多个链接？→ 拆开
- [ ] 有没有在多个群发同样的话？→ 停
- [ ] 有没有 @ 一堆人？→ 删掉

## 5. 最后一件事：**推广前先自己用一遍**

发出去之前，自己走一遍完整流程：
搜一张谱 → 点算 → 看卡片 → 导出分享图 → 发给朋友看看。

如果自己都觉得「这个提示看不懂」「这个按钮找不到」，
外面的人只会更懵。**产品本身就是最好的宣发。**
