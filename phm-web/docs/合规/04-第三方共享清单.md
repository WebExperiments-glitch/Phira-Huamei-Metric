## 汇总

| # | 第三方 | 域名 | 共享什么 | 目的 | 是否含个人信息 |
|---|---|---|---|---|---|
| 1 | Phira 官方 | `phira.5wyxi.com` / `api.phira.cn` | 会话令牌（仅登录时） | 验证身份、读公开资料 | **是**（令牌、UID） |
| 2 | 云托管（WorkBuddy 云服务） | `phm.app.workbuddy.host` | 全部上报数据 | 服务端与存储入口 | **是**（见收集清单） |
| 3 | 云数据库（Neon） | `*.neon.tech`（ap-southeast-1） | 全部上报数据 | 数据存储 | **是**（见收集清单） |

| 5 | 谱面镜像 | `phira.mivik.cn` | 无 | 下载谱面 | 否 |
| 6 | GitHub | `raw.githubusercontent.com` 等 | 无 | 下载资源/更新信息 | 否 |

**不存在**：广告平台、统计 SDK、崩溃分析 SDK、社交分享 SDK、推送服务。

## 分项说明

### 1. Phira 官方 API

| 项 | 内容 |
|---|---|
| 运营方 | TeamFlos / Phira 开发团队 |
| 何时调用 | ① 下载谱面文件 ② 登录/刷新会话 ③ **每次上报时验证身份** |
| 共享数据 | 会话令牌（`x-phira-token`，仅在你登录 Phira 时）、谱面 ID |
| 返回数据 | Phira UID、用户名（我们存入数据库用于区分玩家） |
| 隐私政策 | 见 Phira 官方公示 |

⚠ **重要说明**：每次上报对局时，服务端会把你的 Phira 会话令牌转发给
`https://phira.5wyxi.com/me` 验证身份。这意味着 Phira 官方**能感知到这个验证请求**。
如果你不希望这样，请不登录 Phira 直接游玩（匿名上报仍然有效）。

### 2. 云托管（WorkBuddy 云服务）

| 项 | 内容 |
|---|---|
| 用途 | 承载 `phm.app.workbuddy.host` 站点与服务端接口 |
| 共享数据 | 全部上报数据（经 HTTPS 传输） |
| 数据区域 | 与服务端部署区域一致 |

### 3. 云数据库（Neon）

| 项 | 内容 |
|---|---|
| 用途 | PostgreSQL 数据库托管 |
| 区域 | `ap-southeast-1`（新加坡） |
| 共享数据 | 全部上报数据 + 账号信息（邮箱、密码哈希） |
| 备注 | 数据库不对公网开放匿名读写，仅服务端凭据可写 |

⚠ **跨境传输提示**：数据存储在新加坡。
如果你在中国境内使用，这构成个人信息出境。上线前需评估是否满足
《个人信息保护法》第三十八条的出境条件（如单独同意、安全评估等）。
**这一项当前没有做，属于已知合规缺口。**

### 4–6. 纯内容分发（无个人信息）

| 域名 | 用途 | 说明 |
|---|---|---|
| `files.phira.cn` | 谱面文件 CDN | 服务端直连下载，不带你的身份 |
| `phira.5wyxi.com/files/` | 谱面文件 | 同上 |
| `phira.mivik.cn` | 谱面镜像 | 同上 |
| `raw.githubusercontent.com` | 资源/更新 | 静态拉取 |

这些请求**不携带**你的账号、位置、设备标识。CDN 侧可能记录访问 IP
（这是任何 HTTP 请求的固有属性），但我们不向其提供任何额外信息。

## 我们不会做的事

| 项目 | 状态 |
|---|---|
| 向第三方出售你的数据 | ❌ 从未，也不会 |
| 向广告平台共享 | ❌ 无广告 SDK |
| 向数据分析平台共享 | ❌ 无此类集成 |
| 向第三方提供原始逐音符判定 | ❌ 仅存于我们自己的数据库 |
