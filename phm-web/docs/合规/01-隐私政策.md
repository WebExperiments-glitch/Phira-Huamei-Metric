## 一句话概括

本客户端会把你的**对局结算数据**上传到 `phm.app.workbuddy.host`，用于研究谱面难度。  
其中包含**位置（城市级，约 1 公里精度）**与**陀螺仪摘要**，属于敏感个人信息。  
这两项都可以在「设置 → 账号 → 上报游玩数据」一键关闭，
关闭后本客户端**不再上传任何对局数据**（成绩、判定、设备、位置、陀螺仪全部停止）。

## 2. 我们收集什么

### 2.1 对局结算数据（每次打完一局上传一次）

| 数据项       | 具体内容                                      | 是否可关闭         |
| --------- | ----------------------------------------- | ------------- |
| 成绩        | 分数、准确率、最大连击、Perfect/Good/Bad/Miss 四项计数    | 整体可关          |
| 谱面标识      | 谱面 ID、难度标签、物量（音符数）、谱面内容摘要（SHA-256）        | 整体可关          |
| **逐音符判定** | 每个音符的判定结果与击打偏移（早/晚多少毫秒）                   | 整体可关          |
| 手感特征      | 本局最大同时手指数                                 | 整体可关          |
| **触控落点**  | 8×8 网格的点击热度分布（64 个计数，归一化）                 | 整体可关          |
| 计时完整性     | 实际游玩耗时、谱面时长、二者比值、暂停次数、卡顿帧数                | 整体可关          |
| 设备信息      | 系统版本、机型标识（如 `iPhone15,2`）、屏幕尺寸与像素比、实际渲染尺寸 | 整体可关          |
| **位置**    | 经纬度，**四舍五入到 2 位小数（约 1 公里）**               | 整体可关 + 系统授权可拒 |
| **陀螺仪摘要** | 一局内角速度的**均值、标准差、峰值**三个数（不传原始采样）           | 整体可关          |
| 游戏设置      | 谱速、Mod、是否键盘模式                             | 整体可关          |
| 版本信息      | 客户端版本、判定数据格式版本、结算时刻                       | 整体可关          |

**位置的处理方式**：定位精度请求为 1000 米，拿到坐标后**在写入内存前**就四舍五入到  
2 位小数，原始精确坐标不会离开采集函数、不会落盘、不会上传。  
拒绝系统定位授权后，该字段为空，其余数据照常上报。

**陀螺仪的处理方式**：只上传三个统计量。一局 3 分钟 60Hz 的原始采样约 1 万个点，  
我们不传、也不在本地保留。

### 2.2 明确不收集

以下项目**代码里没有任何采集路径**，可对照源码核实：

- ❌ **设备唯一标识**：不取 IDFA、IDFV、UDID、MAC、序列号
- ❌ 通讯录、相册、麦克风、摄像头、剪贴板
- ❌ 精确位置（原始 GPS 坐标）
- ❌ 你的 Phira 账号密码（只读公开接口，不接收密码）
- ❌ 你在游戏内的聊天内容、好友列表
- ❌ 广告标识符，也无任何广告 SDK

### 2.3 账号（可选）

如果你在客户端里登录**话梅账号**（自建邮箱体系），我们会存：

| 数据项    | 说明                   |
| ------ | -------------------- |
| 邮箱     | 仅用于登录与找回             |
| 密码哈希   | scrypt 加盐哈希，**不存明文** |
| 随机内部标识 | 用于关联你的档案，不对外暴露       |

如果你只登录 **Phira 账号**（不注册话梅账号），我们**不存你的密码**；  
仅在每次上报时把会话令牌转发给 Phira 官方 `/me` 接口验证身份，  
从返回值里取 Phira UID 与用户名。令牌本身不落库。

**未登录也会上报**，此时以匿名方式记录（无法关联到你个人）。

### 2.4 本地诊断日志

为排查故障，客户端会在应用沙盒内写入 `motion.log`（陀螺仪采集诊断）  
与 `panic.log`（崩溃记录），单个文件上限 256 KB 并轮转。

**这两个文件只存在你的设备上，不会自动上传。**  
你可以在「文件」App 的 `我的 iPad → phira-hm` 目录下自行查看或删除。

## 3. 用来做什么

| 用途     | 具体说明                      |
| ------ | ------------------------- |
| 谱面难度研究 | 用大量玩家的真实表现反推谱面难度，替代主观标称定数 |
| 数据质量分析 | 判断哪些数据可信（如卡顿帧过多的一局会降权）    |
| 故障排查   | 定位采集失败（如某机型拿不到陀螺仪）        |

**我们不做的事**：

- ❌ 不做用户画像、不做广告推荐、不向你推送营销内容
- ❌ 不把你的数据卖给任何第三方
- ❌ 不用你的数据做与谱面难度无关的分析

## 6. 你的权利

### 6.1 关闭数据上报（最直接的方式）

**设置 → 账号 → 上报游玩数据**（代码里叫 `telemetry_enabled`）

关闭后：结算页不再发起上传，**不显示「上传中」**——  
这是刻意设计，让你能看出开关确实生效了。
开关放在账号页最上方、四份文档之前，就是为了让它更容易被找到。

⚠ **该开关默认为开启**。我们正在评估改为首次启动时询问（见第 10 节）。

### 6.2 注销账号

客户端内可注销话梅账号。注销会删除：账号、档案、未使用的验证码。

**注意**：注销**不会删除**已经上报的对局数据——  
这些数据在上报时就是匿名或仅带随机内部标识的，已无法回溯到你的邮箱。  
如果你要求删除对局数据，请通过第 1 节联系方式提出，我们会按你的谱面 ID  
与时间范围尽力定位（若当时为匿名上报则技术上无法定位）。

### 6.3 其他权利

依据《个人信息保护法》，你有权查阅、复制、更正、补充、删除你的个人信息，  
并可撤回同意。请通过第 1 节联系方式提出，我们会在 **15 个工作日**内答复。

## 7. 位置与陀螺仪的特殊说明

这两项在《个人信息保护法》下属**敏感个人信息**，单独说明：

**位置**

- 目的：分析「不同地区玩家的设备与网络状况」
- 精度：约 1 公里（四舍五入到 2 位小数）
- 必要性：**非必要**，拒绝后游戏功能完全正常
- 授权方式：iOS 系统弹窗（仅使用期间）
- 撤回：iOS「设置 → 隐私与安全性 → 定位服务 → Phira」

**陀螺仪**

- 目的：分析「手抖程度与判定偏差的关系」
- 内容：仅三个统计量，不含原始采样
- 必要性：**非必要**，拒绝后游戏功能完全正常
- 撤回：随第 6.1 节总开关一并关闭
