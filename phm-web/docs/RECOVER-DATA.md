# 数据恢复工单（可直接粘贴给平台支持）

> 用途：向平台申请**导出 / 恢复** P.H.M. 站点原数据库里的数据。
> 背景：库在 2026-10-21 前后开始对应用侧返回 `DATABASE_RESOURCE_ISOLATED`，
> 现在连读取凭据也失效了（`invalid_client`）。数据本身大概率还在，
> 但我们已经没有任何读取权限。**隔离 ≠ 删除，请先确认数据是否仍然存在。**

---

## 一、我的情况

- 应用名：`P.H.M. 谱面定数参考`
- 应用地址：`https://phm.app.workbuddy.host/`
- 使用的能力：云数据库（PostgreSQL / PostgREST 兼容端点）
- 时间线：
  - 2026-10-20 起，应用侧调用数据库开始返回 `DATABASE_RESOURCE_ISOLATED`
  - 2026-10-21，同一个库的写入凭据（publishable key）也返回
    `401 {"error":"invalid_client","error_description":"the client credential is invalid or revoked"}`
  - 我判断触发原因是 `hm_rate`（限流计数）表只增不减，把存储额度吃满了

## 二、我要什么（按优先级）

1. **确认数据是否还在**（是否只是隔离，没有被删除）
2. **导出以下表的数据**（CSV 或 SQL dump 都行，越快越好）：
   - `hm_accounts`（自建账号：sub / email / pass_hash / salt / created_at）
   - `phm_scores`（玩家成绩上报）
   - `hm_api_keys`、`hm_api_usage`（开放平台的 Key 与用量）
   - `phm_charts`（谱面分析缓存 —— 这张如果导不出来也可以，我能重算）
   - `hm_profiles`、`hm_status_hour`（档案与状态历史）
3. 如果无法导出，请告知**恢复访问需要什么条件**（升级套餐 / 清理超额数据 / 等额度重置）

## 三、我已经排除的可能

- 本地没有备份（`backups/` 为空，仓库历史里从未提交过任何 dump）
- 远程直读不可行（凭据已被吊销，401）
- 所以除了平台侧，没有第二条路

## 四、补充说明

- 数据量不大：账号是邮件+密码哈希，成绩是玩家提交的分数行，缓存是分析结果。
- `phm_charts` 我可以自己重算（引擎是确定性的），**请优先保全账号和成绩**。
- 导出物里含密码哈希（scrypt + 独立盐），请通过安全渠道交付。

## 附：给用户自己的三条备忘

1. **先别清理任何东西** —— 别去控制台删表、删应用。删了就真没了。
2. 控制台里如果有「数据库 → 备份 / 导出」入口，**先自己点一次导出**，比等工单快。
3. 如果平台说必须升级套餐才能解除隔离：先问清楚「升级后数据还在不在」，
   再决定花不花这笔钱 —— 有些隔离是不可逆的，那就只能接受损失。
