P.H.M. Standard 隐私政策

版本 v1.3 · 生效日期 2026-10-17 · 适用站点 phm.app.workbuddy.host
本协议以简体中文版本为准；英文译本仅供参考。

一句话概括：你的谱面文件永远不会离开你的设备；只有当你查询 你自己确认过的 Phira 账号时，才会把成绩数据（Phira UID、用户名、谱面名、定数、ACC、单曲 RKS） 自动上传，用于校准定数参考。这可以在设置里一键关闭， 关闭后不会上传任何贡献内容。

1. 我们收集什么

1.1 你主动拖入的谱面文件——文件本身不收集

谱面解析（ZIP 解压、谱面结构分析、特征提取、定数计算）全部在你的浏览器内完成。 谱面文件本身不会上传、不会留存、不会离开你的设备。

在你允许自动上传的前提下，会离开设备的只有由该谱面计算出的结构特征，它们不含谱面内容本身：

  • 谱面名与标称定数
  • 物量、每秒音符数（NPS）、长条占比、纵连均值、线速峰值
  • 计算得到的参考定数与负荷分（PS）

这条路径不需要登录，也不需要你点按钮 ——拖入谱面时自动完成贡献。 但它受设置里那个开关统一控制：关闭自动上传后，拖入谱面不会产生任何上传。

1.2 查询 Phira 账号时的成绩数据——仅对本人账号，且可关闭

当你在页面里输入 Phira 用户名或 UID 并查询时：

  • 首次遇到某个 UID：会问你一次「这是你自己的账号吗」—— 答「是」才把它记为本人账号；答「否」则只查看、不上传
  • 对已确认的本人账号：自动上传成绩数据（见下表）

为什么要多问一句：本工具无法验证 Phira 账号的所有权（Phira 未提供第三方授权登录）。 如果不加确认，任何访问者都能把某个公开玩家的成绩复制进数据集，那样所有统计都会失真—— 所以只对你自己声明过的账号自动上传。

收集项说明
Phira UID 与用户名用于区分不同玩家，避免同一份成绩被重复计数
谱面名、标称定数用于关联成绩与谱面
你的 ACC、单曲 RKS用于分析「同一标称定数下玩家实际表现的分布」
一个随机假名标识 client_id 用于区分不同来源的贡献。这是假名化标识、不是匿名 —— 同一浏览器贡献的多条数据可以被关联起来。我们不会把它与你的真实身份绑定， 但请知悉它并非不可关联。

不会收集：Phira 账号的密码或登录凭据，也不会请求任何 Phira 操作权限。查询只读 Phira 的公开数据接口 （api.phira.cn），不要求也不接受你的 Phira 密码。邮箱与密码只在你主动注册 P.H.M. / huamei 账号时处理（见 1.4）。

1.3 本地存储（仅存在你自己的浏览器里）

以下信息只存在你浏览器的 localStorage 里，不会自动上传：

  • 你输入过的 Phira 用户名 / UID（用于下次自动填充）
  • 自动上传开关的状态、首次告知的确认状态
  • 一个随机生成的 client_id（8 位随机串，用于区分匿名打卡来源）
  • P.H.M. / huamei 账号的登录令牌（若你登录了账号；不含密码）

1.4 账号系统（可选）

只有你主动注册时才涉及，用于登录、绑定 Phira 账号、查看与修改你自己的资料。目前有两种可选账号：
① 网页端账号：注册 / 登录由 WorkBuddy 云服务的认证模块处理，平台保存邮箱与密码哈希，本站只拿到会话令牌；
② Windows 客户端 huamei 账号：注册 / 登录由本站服务端处理。明文密码只在 HTTPS 请求中进入服务端内存，随即用 scrypt 哈希后存入 WorkBuddy 云 PostgreSQL 的 hm_accounts 表（只存邮箱、盐与哈希），不写日志；注册需要邮箱验证码，登录只要密码。
两种情况下本站都无法读取你的明文密码，也从不收集 Phira 密码。

2. 收集来做什么

  • 校准定数参考：统计同一标称定数下玩家 ACC 的分布，识别标称与实际难度的偏离
  • 共享定数缓存：让其他人搜到同一张谱时不必重复下载与计算
  • 展示聚合统计：如「成绩数据 N 条」「定数缓存 N 张」这类总数

我们不将这些数据用于广告、画像，或向第三方出售。

3. 对外可见性

其他人看不到你的 UID 或用户名。成绩明细表（phm_scores）已撤销匿名读取权限。 外部只能通过两个聚合接口取数，且它们只返回统计量：

  • phm_plays(谱面名) → 该谱的条数 / 平均 / 中位 / 最低 / 最高 ACC
  • phm_stats() → 全局总数（账号数、活跃数、成绩总数等）

两者都不返回任何一条具体的个人记录。

4. 存储与安全

  • 数据存储在 WorkBuddy 云服务（中国大陆境内）的 PostgreSQL 数据库中
  • 谱面文件不上传，因此不存在谱面内容的存储风险
  • 写入必须经过本站服务端网关的字段校验与速率限制
  • 我们不保证绝对安全 ——任何网络服务都存在被攻击的可能。请不要上传任何敏感信息

更完整的技术细节（信任边界、已修复与已知的局限）见仓库中的 docs/SECURITY.md。

5. 你的权利

权利怎么做
关闭上传设置 → 关闭「自动上传」。立即生效，之后不再上传谱面结构特征与成绩数据
撤回首次同意设置 → 撤回确认。下次上传前会重新征求你的同意
清空本地数据设置 · 本机存储 → 一键清空（不影响服务器数据）
只查看、不贡献查询 Phira 账号时回答「不是我的账号」，即只查看、不上传
删除已上传的数据见下方「如何安全地联系我们」
导出你的数据同上，可申请导出
注销账号设置 · 账号管理 → 「注销账号」可自助删除网页端账号在本站的资料（Phira 绑定、显示名、访问计数）。
huamei 账号（Windows 客户端）可发邮件申请删除 hm_accounts 中对应行（邮箱、盐、密码哈希）；平台侧登录邮箱如需删除，需另行申请，我们核验身份后协助处理。
贡献过的成绩不在注销范围：它们本来就是匿名的，不挂在你的账号上。

如何安全地联系我们（请不要在公开 Issue 里写隐私信息）

本站的公开协作区（GitHub Issues）是任何人都能看到的。为了请求删除数据而在那里贴出你的 Phira UID 或邮箱，等于把你的隐私标识公开——这正是我们要避免的。请改用下面任一方式：

  • GitHub 私密安全报告（推荐，仅仓库维护者可见）：
    github.com/WebExperiments-glitch/Phira-Huamei-Metric/security/advisories/new
  • 若该入口不可用，可先在公开 Issue 里只说「需要删除我的数据」， 等维护者回复后再通过私密渠道交换标识信息

我们收到请求后会删除对应记录，并在完成后回复确认。处理时间为收到请求后的 7 个工作日内。

6. 未成年人

本工具面向音游玩家群体，可能存在未满 14 周岁的使用者。

如果你是未满 14 周岁的未成年人，请在监护人的陪同下阅读本政策，并取得监护人的同意后 再使用登录与数据上传功能。若监护人不同意，请关闭自动上传或不要登录 Phira。

监护人如发现未成年人未经同意上传了信息，可通过上述私密渠道联系我们删除。

7. 个人信息对外提供清单

本站不向任何第三方出售个人信息。下面是把个人信息交给外部服务商的全部情形 —— 逐项写明接收方、联系方式、处理目的、处理方式与信息种类。

  • WorkBuddy 云服务（腾讯） —— 数据库托管、静态分发、网页端账号认证、邮箱验证码发送。
    联系方式：平台客服；也可由本站转达（见第 10 节）。
    处理方式：传输与存储加密；启用行级安全；huamei 账号的密码仅以 scrypt 哈希存储，明文不落库、不写日志。
    涉及信息：登录邮箱、密码哈希、账号标识、绑定的 Phira UID 与显示名、邮箱验证码状态、贡献的成绩。
  • Phira（api.phira.cn） —— 读取公开的谱面元数据与谱面文件，供定数计算。
    联系方式：以 phira.cn 公示的渠道为准。
    处理方式：由本站服务端发起 HTTPS 只读请求，不随附你的账号身份或登录凭据。
    涉及信息：谱面 id、谱师 uid（均为公开数据）；你查询玩家时发出的用户名 / UID。
  • jsDelivr CDN（jsdelivr.com） —— 分发云服务 SDK 脚本。
    联系方式：jsdelivr.com。
    处理方式：常规 CDN 静态分发；脚本版本已用 SRI 完整性校验钉死，本站不向其发送任何账号信息。
    涉及信息：IP、User-Agent（CDN 服务的固有行为）。

此外没有任何其它对外提供：本站不接入广告或数据分析 SDK，不向第三方出售或交换个人信息。

8. 我们不做什么

  • 不使用 Cookie 做跨站追踪（本站在浏览器本地只使用 localStorage）
  • 不接入任何广告或数据分析 SDK
  • 不推断、不判定「谱师虚标」——本工具只给难度参考
  • 不向任何第三方出售或分享你的个人信息

本政策如有更新，会修改页面顶部的版本号与生效日期。涉及收集范围扩大的变更， 会在站内显著位置提示，并重置「首次告知」状态以重新征求你的同意。

v1.3（2026-10-17）：明确自建 huamei 账号的数据处理（邮箱与 scrypt 密码哈希存入 hm_accounts，明文不落库）；修正「不会收集密码 / 邮箱」的表述，使其仅指 Phira 凭据；补充 huamei 账号的注销路径。收集范围没有扩大。
