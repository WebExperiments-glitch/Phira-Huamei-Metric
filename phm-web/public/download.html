怎么用

  1. 下载上面那个 .exe，放到任意目录，双击即可运行——单文件，不需要安装，也不需要额外的资源文件夹。
  2. 首次启动会被 Windows 拦一下（见下面那条说明），选「更多信息 → 仍要运行」。
  3. 在客户端里用你自己的邮箱登录站内账号（收验证码即可，不需要 Phira 密码），然后在设置里确认已登录。
  4. 从谱面库选一张谱开打。结算时这一局的逐音符判定会自动上报——没登录就不会上报，其余功能照常。

校验下载（可选，但建议）

这个包没有代码签名。要确认下载到的文件没被中途篡改，把它的 SHA-256 和下面这串对一下。
—
Get-FileHash $env:USERPROFILE\Downloads\phira-huamei.exe -Algorithm SHA256
在 PowerShell 里跑上面这行，比对 Hash 一栏。把路径换成你实际存放的位置。
运行时会看到「Windows 已保护你的电脑」——这是 SmartScreen 对所有未做代码签名的程序的标准提示，不是检测到了病毒。点「更多信息」→「仍要运行」。代码签名证书要按年付费，这个项目目前没有买。
