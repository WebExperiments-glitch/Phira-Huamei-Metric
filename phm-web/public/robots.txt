# P.H.M. Standard —— Phira 谱面难度参考
User-agent: *
Allow: /

# 接口不给爬。
# /api/analyze 是全站最贵的路径：未命中缓存时要下载谱面包（最多 60MB）并跑完整引擎。
# 让它被爬虫批量命中，等于把带宽和 CPU 白送出去。
Disallow: /api/

# 玩家页不给爬：它按 UID 展示某个人的成绩与游玩历史。
# 这些数据在 Phira 站内是公开的，但**「公开可查」不等于「该被搜索引擎收录」** ——
# 被 Google/Bing 索引之后，别人搜某个玩家名会直接搜出他的成绩单。
# /charter 是有意公开的（谱师的作品集本来就是给人看的），所以不挡。
Disallow: /user

# 数据管理页也不给爬：它是给人看运维状态的表格页，
# 被搜索引擎收录只会带来无意义的抓取（而且它自己发了 noindex）。
Disallow: /data

# 设置页不给爬：它列的是「我这台设备上存了什么」（本人账号声明的 UID 等）。
# 而且对爬虫来说它永远是未配置的空状态，收录毫无意义（它也自己发了 noindex）。
Disallow: /settings
