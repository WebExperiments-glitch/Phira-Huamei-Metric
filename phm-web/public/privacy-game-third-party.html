分项说明

1. Phira 官方 API

运营方TeamFlos / Phira 开发团队
何时调用下载谱面文件；登录/刷新会话；每次上报时验证身份
共享数据会话令牌（x-phira-token，仅在你登录 Phira 时）、谱面 ID
返回数据Phira UID、用户名（我们存入数据库用于区分玩家）
隐私政策见 Phira 官方公示

重要说明：每次上报对局时，服务端会把你的 Phira 会话令牌转发给 https://phira.5wyxi.com/me 验证身份。这意味着 Phira 官方能感知到这个验证请求。 如果你不希望这样，请不登录 Phira 直接游玩（匿名上报仍然有效）。

2. 云托管

承载 phm.app.workbuddy.host 站点与服务端接口。全部上报数据经 HTTPS 传输。

3. 云数据库（Neon）

PostgreSQL 数据库托管，区域 ap-southeast-1（新加坡）。 存储全部上报数据与账号信息（邮箱、密码哈希）。数据库不对公网开放匿名读写，仅服务端凭据可写。

跨境传输提示：数据存储在新加坡。如果你在中国境内使用， 这构成个人信息出境。上线前需评估是否满足《个人信息保护法》第三十八条的出境条件 （如单独同意、安全评估等）。这一项当前没有做，属于已知合规缺口。

4–6. 纯内容分发（无个人信息）

这些请求不携带你的账号、位置、设备标识。CDN 侧可能记录访问 IP （这是任何 HTTP 请求的固有属性），但我们不向其提供任何额外信息。
