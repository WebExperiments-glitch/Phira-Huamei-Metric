An auditable difficulty reference for Phira charts.

Drop a chart pack. We extract five structural features, place them against 1,037 official charts and 9,508 community charts by k-nearest-neighbour, and give you a number on the same scale as the official rating.

We do not call anything mis-rated. We publish numbers and their uncertainty — every value on the result card can be traced back to a feature you can inspect.

A chart pack is the file Phira downloads for a chart (.pez), or a .zip containing info.yml and the chart itself. Everything is parsed locally — nothing is uploaded.
How to read the numbers
Reference — k-NN result over 9,508 community charts (plus 1,037 official charts as a second scale), on the same scale as the official rating. Load (PS) — our own 0–20 load scale (density / pattern / coordination / stamina); independent of the official rating.
Features: notes per second · hold ratio · note count · stair speed · peak judgement-line speed — all computed from the chart file only.
