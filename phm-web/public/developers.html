P.H.M. API

Phira / Phigros 谱面难度参考接口。查询已缓存的定数，或分析一张谱并写入共享缓存。 免费；匿名可用，API Key 获得更高额度。

返回的是「点估计 + 不确定带」：ref_const 是社区共识标度， ref_official 是官谱标度。两者不可混比，细节见首页说明。

快速开始

API 是普通的 HTTPS + JSON，不需要 SDK。先拿到一个 API Key（开放平台），或者直接用匿名额度试：

# base_url https://phm.app.workbuddy.host/api/v1 # 匿名也可以，只是额度低 curl https://phm.app.workbuddy.host/api/v1/charts/22681

带 Key 的请求：

curl https://phm.app.workbuddy.host/api/v1/charts/22681 \ -H "Authorization: Bearer sk-你的key"

JavaScript：

const res = await fetch( "https://phm.app.workbuddy.host/api/v1/charts/22681", { headers: { Authorization: "Bearer sk-你的key" } } ); const chart = await res.json();

Python：

import requests r = requests.get( "https://phm.app.workbuddy.host/api/v1/charts/22681", headers={"Authorization": "Bearer sk-你的key"}, timeout=30, ) print(r.json())

认证

两种身份：

  • 匿名：不带 Authorization，按真实对端 IP 限流；
  • API Key：Authorization: Bearer sk-<32 位十六进制>。

Key 的明文只会在创建时返回一次；服务端只存 sha256 哈希与掩码。每个账号最多 100 个有效 Key，可随时吊销。

开放平台登录使用站点账号；API Key 与账号密码相互独立，不要把 Key 写进前端代码或公开仓库。

限流

身份额度说明
匿名100 次/小时真实对端 IP + 全局桶
API Key1000 次/小时分析另有 200 次/天

超限返回 429，并带 retry-after；服务端限流器不可用时返回 503。

查询定数

GET /charts/{chart_id}

读共享缓存。未分析过的谱返回 analyzed:false（不是 404）。

{ "chart_id": 22681, "name": "Pandemic", "level": "IN.16", "difficulty": 16.6, "ref_const": 15.6, "ref_official": 16.1, "ps_score": 13.4, "engine_ver": "server-verified", "engine_build": "com-trim15-v0.5.0", "analyzed": true, "cached": true }

分析谱面

POST /analyses

服务端从 Phira 下载谱面、复算并写入共享缓存。v1 只接受 chart_id；分析结果对之后所有查询直接可用。

curl -X POST https://phm.app.workbuddy.host/api/v1/analyses \ -H "Authorization: Bearer sk-你的key" \ -H "content-type: application/json" \ -d '{"chart_id": 22681}'

已缓存时直接返回（cached:true）；未缓存时会下载 ≤60MB 谱面并运行引擎，可能需要几秒。并发上限 2，忙时返回 503 analysis_busy。

用量

GET /usage

用 API Key 调用时返回该 Key 所属账号的用量；开放平台用账号 token 调用也可以。

{ "today": 12, "week": 87, "month": 312, "by_endpoint": { "/charts": 280, "/analyses": 32 }, "quota": { "hourly": 1000, "analysisDaily": 200 } }

Key 管理

在 API 开放平台 登录后创建、改名、设置权限/到期、轮换、吊销。删除（吊销）后 Key 会立即从列表消失，历史用量仍保留。

Scopes：charts:read（查询）、analyses:write（分析）、usage:read（用量）。 缺 scope 返回 403 insufficient_scope；过期返回 401 expired_api_key。 创建时可设 30/90/365 天或永不过期；轮换会新建同权限 Key 并立即吊销旧 Key。
方法路径说明
GET/keys列出当前账号的有效 Key（吊销后不再返回；不含明文）
POST/keys创建，返回一次明文；body 可带 scopes[] / expires_in_days
PATCH/keys/{id}改名 / 改 scopes / 改到期
POST/keys/{id}/rotate轮换：新 Key + 吊销旧 Key
DELETE/keys/{id}吊销

这些接口要求网页账号 token（x-hm-token），不是 sk- key。

错误码

错误统一为：

{ "error": { "type": "invalid_request_error", "code": "invalid_chart_id", "message": "..." } }
HTTPcode含义
400invalid_chart_idchart_id 不是正整数
401invalid_api_keyKey 不存在、格式错或已吊销
401account_token_requiredKey 管理需要登录
401expired_api_keyKey 已过期
403insufficient_scopeKey 缺少该接口所需 scope
409key_limit_reached账号已有 100 个有效 Key
429rate_limit_exceeded超出小时额度
502analysis_failed / cache_unavailable上游或数据库暂时不可用
503analysis_busy / rate_limit_unavailable分析并发已满 / 限流器故障
