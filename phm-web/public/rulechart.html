规则说明

拍网格按难度细分（4/8/16 分音符），段落密度按 intro / 主歌 / 副歌递增； 音符类型与轨道按权重和乐句模式（alternate / stair / flow / jump / stream / burst）选择。 高难度会在强拍加入和弦，Hold 有最短/最长拍数限制，同轨有最小间隔。 同一组参数 + 种子可复现；换种子会得到不同排布。
