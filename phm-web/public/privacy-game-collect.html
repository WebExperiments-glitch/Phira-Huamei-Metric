分项说明

1–6、10–11：每次对局自动上报

这几项构成一局完整的成绩记录，随结算一次性上传。其中第 3 项（逐音符判定） 是难度研究的核心资产——它告诉你「哪些音符被打空」，而不只是「整曲平均多少分」。 存储位置：云数据库 hm_plays 表。

7：设备信息

字段示例说明
os_version17.0系统版本
modeliPhone15,2硬件标识（sysctl hw.machine，非营销名）
screen[390, 844, 3]逻辑宽、逻辑高、像素比
view[390, 844]实际渲染区像素（折叠屏/分屏时需要）

不含任何设备唯一标识（无 IDFA / IDFV / UDID / MAC / 序列号）。

8：位置（敏感）

  • 请求精度：1000 米
  • 存储精度：2 位小数 ≈ 1.1 公里
  • 取整时机：写入内存之前，原始坐标不离开采集函数
  • 采集频率：结算时读一次（不是全程追踪）
  • 拒绝授权：字段为空，其余数据照常上报
  • 撤回：iOS 设置 → 隐私与安全性 → 定位服务 → Phira

9：陀螺仪摘要（敏感）

只传 [均值, 标准差, 峰值] 三个数，单位 rad/s。 不传原始采样——一局 3 分钟 60Hz 约 1 万个点，我们不传也不在本地保留。 采集不足 10 帧时不上报（局太短，没有统计意义）。

12–15：账号（可选）

只有你主动注册话梅账号才会产生。不注册则以匿名方式上报，功能不受影响。 注销账号会删除：账号、档案、未使用验证码。不删除已上报的对局数据（上报时已匿名，无法回溯）。

16：本地日志

文件位置大小上限上传
motion.log应用沙盒 Documents/256 KB，轮转否
panic.log应用沙盒 Documents/256 KB，轮转否

可在「文件」App → 我的 iPad → phira-hm 查看或删除。

明确不收集

项目状态
设备唯一标识（IDFA/IDFV/UDID/MAC/序列号）代码中无采集路径
通讯录 / 相册 / 麦克风 / 摄像头不申请权限
剪贴板不读取（仅用户点「复制」时写入，从不读回上传）
精确 GPS 坐标仅保留约 1 公里精度
Phira 账号密码只读公开接口，不接收密码
游戏内聊天 / 好友列表不采集
广告标识符无广告 SDK
崩溃自动上报无此类 SDK，日志仅存本地

收集方式

时机触发
启动时采集设备信息一次；请求定位授权；启动陀螺仪采样
对局中陀螺仪连续采样（仅在内存中累计统计量）；触控落点累加进 8×8 网格
结算时组装全部字段，一次 HTTPS POST 上传
注册时仅在主动注册时提交邮箱与密码

不存在后台定时上报、不存在「静默补传历史数据」的行为。
