## ⚠️ 这个工具不做的事（先说清楚）

**本工具不判定「虚标」。**

理由是可测量的，不是谦辞：

```
官方标注噪声实测 = 2.80 级
（用「同曲 + 物量相近的相邻难度」做噪声代理，n=70，定数差中位 2.80）
```

也就是说，**当两首谱的物量相差不到 15% 时，官方给它们的定数仍差 2.8 级。**

在这个噪声水平下，任何工具都无法区分：
- 「谱师标错了」
- 「官方也会这么标」

**声称能区分，就是造假。**

## 一、那么这个工具做什么

### 1. 给参考区间（不给点值）

定数的 0.1 是**机械精度**（编辑器滑块最小刻度），不是**语义精度**。

证据 —— 社区谱定数取值分布：

```
15.0  694 张  (7.3%)   ← 整数最多
14.0  520 张  (5.5%)
16.0  400 张  (4.2%)
15.4  178 张  (1.9%)
15.6  178 张  (1.9%)
```

**整数比一位小数常用 3.9 倍** —— 这是「拖滑块」的指纹。

所以输出是区间，不是数字。

### 2. 给特征差异（可争论）

不说「你错了」，说「同类通常是这样」：

```
NPS（每秒手数）      8.86   同类中位 6.68   百分位 86%   偏高 33%
物量              1702   同类中位 888   百分位 99%   偏高 92%
Hold占比          14.57   同类中位 23.3  百分位 25%   偏低 38%
纵连速度           0.00   同类中位 12.4  百分位  0%   偏低 100%

→ 物量与手速显著高于同类，但强度分散特征偏低
```

### 3. 给官谱参照（完全可查证）

```
与你的谱最相似的官谱：
  Cthugha          IN 16.0  NPS 8.96  物量 1333
  BANGING STRIKE   IN 15.9  NPS 8.89  物量 1248
  白と黒のバケモノ  IN 15.9  NPS 8.97  物量 1197
→ 这 5 首官谱的定价为 15.9 ~ 16.0
```

相似度算式公开，参照谱可查证。

### 4. 四条事实性检查（不依赖任何模型）

| 检查 | 依据 | 性质 |
|---|---|---|
| **定数 > 18.0** | 官谱 1,037 条无一超过（DesultorySignals AT） | **硬事实** |
| **难度标签与定数区间矛盾** | 实测官谱 EZ 0.5–10 / HD 3.5–14 / IN 7–17 / AT 13.4–18 | 事实 |
| **Liveness 双字段冲突** | phira.moe 前端校验器同款规则 | 硬规则 |
| **与同类中位偏离 ≥ 2.0** | 同标签同物量区间的中位 | 统计异常 |

前三条**不依赖任何模型**，可以直接引用。

## 二、可复现性（本项目的核心承诺）

### 公式只有 2 个维度

```
定数参考 = 查表( 难度标签, NPS档, Hold%档 )
```

档位定义：

```
NPS 档：  0 | 2.5 | 4.5 | 6.5 | 10 | ∞
Hold 档： 0% | 12% | 25% | 40% | 55% | 100%
```

### 为什么只有 2 个维度

我实测了 18 维要素，加上去**精度反而下降**：

| 方案 | MAE | p90 |
|---|---|---|
| **2 维（采纳）** | **0.700** | **2.000** |
| + 4 维 | 0.800 | 2.250 |
| + 6 维 | 0.900 | 2.500 |
| + 11 维 | 1.300 | 4.000 |

**根因：要素信号（偏相关 0.12~0.52）远小于官方噪声（2.80）。**

在 1,037 条样本上细化到 0.12 量级的偏相关，就是在拟合噪声。

### 精度

留一法（每条留出、用其余建表）：

| 指标 | 值 |
|---|---|
| 误差中位 | 0.700 |
| p75 | 1.300 |
| p90 | 2.000 |
| ≤1.0 占比 | 68.5% |
| ≤1.5 占比 | 约 85% |

**对照：官方自身同格内离散度 p90 = 2.00**
**我们的公式误差（2.00）与官方标注噪声（2.00）持平。**

### 18 维不是没用，是不用在定价上

它们用于**解释**与**谱型分类**：

| 维度 | 控制 NPS 后偏相关 | 用途 |
|---|---|---|
| stair_speed_avg（纵连） | **+0.5232** | 解释「为什么难」 |
| hold_interference_index（长押） | **−0.4667** | 解释 |
| chord_size_entropy（和弦熵） | +0.2532 | 解释 |
| cross_hand_density（交叉手） | +0.2464 | 解释 |
| eff_peak_tps_1s | −0.0766 | 谱型分类 |
| tempo_change_count | +0.0734 | 谱型分类 |

**定价用 2 维（可审计），解释用 18 维（有信息）。**

## 三、与竞品的区别

| | `phigros_difficulty_estimator` | Phira Verdict |
|---|---|---|
| 输出 | 单一预测数字 | 区间 + 特征差异 + 官谱参照 |
| 特征 | 333 个 | 定价 2 个 + 解释 18 个 |
| 模型 | GB 树（不可解释）+ 56 项权重 | 分层查表（100% 可追溯） |
| 可审计 | 需读源码反推 | **每个格子能追溯到具体官谱** |
| 争议时 | 「我的模型更准」 | **「你跑一遍就知道」** |
| 分布外 | 发散风险（实测 −1298） | 降置信度，明确标「不确定」 |
| 许可 | MIT | 开源 |

**核心差异**：我们输出的是「你和同类的差距」，它输出的是「我算的数」。

## 四、项目定位

> **不是**：定数裁判 / 虚标检测器 / 官方标准复现
>
> **是**：把谱师「心里有数」但从未成文的那套标准，量化成可复核的参照

**为什么有市场**：
社区现在的问题是「定数无标准 → 无法互相校对 → 只能问『你们觉得难吗』→ 得到模糊回答」。

显影工具给的是**可复核的答案**。

**为什么别人做不到**：
需要同时具备
1. 官谱 APK 提取能力（拿真值）
2. 1,037 条定数的分布统计
3. 愿意为了可审计性放弃 0.19 的精度

## 五、报告示例

见 `reports/` 目录。结构：

```
【参考区间】—— 基于官谱实测映射，非「你的定数是多少」
  同类定数区间 [14.6, 15.7]  中位 15.2
  置信度 high（官谱同标签同NPS同Hold档，n=64）
  你的标注 15.3 落在区间内

【特征对照】—— 你和同难度标签官谱的差距
  （4 个特征，各自的值/中位/百分位/偏离%）

【官谱参照】—— 与你最相似的官谱及其定价
  （5 首，含相似度）

【事实性检查】—— 不依赖模型，可直接核验
  （4 条，每条附依据）

【本工具不做的事】
```

## 六、复现

```bash
# 1. 提取官谱（需 MuMu 已装 Phigros）
python tools/extract_pgr.py --apk phigros.apk --out . --charts
python tools/extract_difficulty.py --apk phigros.apk --out . --typetree <tt.json>

# 2. 建基线 + 要素
python tools/build_official_baseline.py --pgr _research/pgr --out data/official/manifest.jsonl
python tools/enhance_features_v3.py --pgr _research/pgr --baseline data/official/manifest.jsonl \
       --out data/official/manifest_v3.jsonl

# 3. 社区谱特征
python tools/extract_community_features.py --manifest data/charts/manifest.jsonl \
       --root data/charts --out data/community/manifest_features.jsonl
python tools/add_community_dims.py --manifest data/charts/manifest.jsonl \
       --root data/charts --out data/community/manifest_v2.jsonl

# 4. 生成报告
python verdict/verdict_report.py --model data/official/manifest_v3.jsonl \
       --chart data/community/manifest_v2.jsonl --id 22681
python verdict/verdict_report.py --model data/official/manifest_v3.jsonl --batch
```

全部纯标准库，无第三方依赖，100% 可复现。
