## 三、两个格式陷阱（血泪教训）

### 陷阱 1：RPE 与 PECTX 的 type 编号一致，但极易记错

官方 `parse/pec.rs` 与 `parse/rpe.rs` 的映射**完全相同**：

| type | 含义 | 判定区间 |
|---|---|---|
| 1 | Click (Tap) | ±80ms |
| 2 | Hold | ±80ms |
| **3** | **Flick** | ±140ms |
| **4** | **Drag** | ±140ms |

**我最初把 3/4 写反了**（误标 `n3`→Drag、`n4`→Flick），自查时从源码发现并修正。

**若不修正，Drag 与 Flick 的全部统计会互换** —— 而这两个恰恰是难度建模的关键特征。

### 陷阱 2：假键率的分母

`假键率 = fake / notes_real` 可以超过 100%（最大 2,854%），因为有些谱假键远多于真键。

**正确口径**：`假键 / (假键 + 真键)`，上限 100%。

| 口径 | r | 最大值 |
|---|---|---|
| 假键/真音符 | −0.0104 | 2,854% ← 口径错误 |
| **假键/总音符** | **−0.0449** | **97%** ← 正确 |

两种口径相关性都极弱，**主结论不受影响**，但 §五 的发现依赖正确口径。

## 五、★ 新发现：假键流谱（34 张）

### 5.1 现象

谱 28873《R.I.P.》有 **13,852 个假键、1,132 个真音符**（假键占 92.5%）。

假键流谱（`fake > real`）共 **34 张（0.4%）**：

| 谱名 | 假键 | 真音符 | 定数 |
|---|---|---|---|
| CROSS†SOUL | 22,975 | 805 | 16.4 |
| **R.I.P.** | 13,852 | 1,132 | **16.8** |
| Precipice | 13,609 | 826 | 15.2 |
| Future Downloaded | 8,364 | 1,743 | 16.2 |
| Melodiniq | 6,934 | 1,753 | 16.9 |

### 5.2 控制物量后的对比

| 群体 | n | 物量中位 | Tap% | 定数中位 |
|---|---|---|---|---|
| 假键流谱 | 34 | 920 | 51.2 | 15.05 |
| 无假键谱 | 4,881 | 1,063 | 59.5 | 15.00 |

**同物量区间 [400, 1200] 内：**

| 群体 | n | 定数中位 |
|---|---|---|
| 假键流谱 | 20 | **15.15** |
| 无假键谱 | 2,845 | 14.60 |
| **差异** | | **+0.55** |

### 5.3 结论修正

**「假键对定数无影响」需要修正。**

- 整体相关系数确实极弱（r = −0.045）
- **但在同物量条件下，假键流谱定数高 0.55**

**机制推断**：假键本身不增加操作负担，但**大量假键构成视觉干扰**，需要额外读谱能力。谱师给高定数是合理的。

→ **假键率应作为「读谱干扰」维度的特征，而非直接计入密度。** 对应 namu.wiki 的「配置集中 `#1A1`」记号。

⚠️ **样本仅 34 张，此结论标记为「假设」，需更多数据验证。**

## 八、最终权重方向

```
正向：物量(最强 +0.266) → Tap%(+0.219) → BPM(+0.146)
负向：Flick%(−0.162) → Drag%(−0.131)
无关：Hold%(谱型混淆)、判定线数、BPM段数、背面%、假键率(整体)
特殊：假键流谱（假键>真音符）在同物量下 +0.55 → 需独立维度
```

### 音符物理权重（基于判定区间，待回归验证）

```
Tap    1.00   ±80ms   需精准点击
Drag   0.55   ±140ms  只需接住
Flick  0.35   ±140ms  只需划到
Hold   按时长加权
```

⚠️ 与偏相关方向一致：Tap 正、Drag/Flick 负。

### 必须用分段函数

- **Drag% > 20%** → 断崖（15.06 → 13.27）
- **Tap% > 60%** → 饱和（+0.01）
- **Flick% > 76%** → 崩塌（15.05 → 11.64）
- **物量在定数 12–13 档有反常凹陷**

### 抽象谱需独立模型

对应 namu.wiki 的 `#1A1`（配置集中）或 `#92A`（个体差），不是虚谱/水谱。
