## 三、★ 关键验证：官方定数确实违反「2.5.0 精度规则」

社区 Wiki 声称：

> 「2.5.0 版本后，7 级及以下只有 x.0 和 x.5，7 级以上有 x.1~x.9 但**不会有 x.0**」

**实测官谱数据：违反 55 处 / 1,037 个定数（5.3%）**

全部违反类型：**8 级以上出现 `x.0`**

```
10.0  9.0  8.0  15.0  8.0  9.0  14.0  11.0  15.0  9.0 ...
```

**结论必须修正**：

| 说法 | 状态 |
|---|---|
| 「官方规定 7+ 以上无 x.0」 | ❌ **被官方数据否证** |
| 「7 级及以下只有 x.0/x.5」 | ✅ 成立（未发现违反） |

**实际影响**：那条社区规则**不能作为硬校验器使用**。

我们原计划用它「零成本判虚标」——**这个方案作废**。若强行使用，会把 5.3% 的合规官谱误判为违规。

→ 校准器必须以**官方真实定数数据**为准，而非社区推导的规则。

## 七、完整数据链路（可复现）

```bash
# 1. 拉 APK（需 MuMu 已装 Phigros）
adb -s 127.0.0.1:16384 pull /data/app/~~*/com.PigeonGames.Phigros-*/base.apk phigros.apk

# 2. 提取谱面（Addressables）
python tools/extract_pgr.py --apk phigros.apk --out . --charts

# 3. 提取定数（data.unity3d）
python tools/extract_difficulty.py --apk phigros.apk --out . \
       --typetree _research/Phigros_Resource-master/typetree.json
```

依赖：`pip install UnityPy==1.10.18`
