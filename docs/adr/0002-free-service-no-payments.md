# ADR-0002：免费服务，不接入支付

- **状态**：已接受（2026-10-17）

## 背景

讨论过商业化与微信支付。调研结论：自然人不能直接申请微信支付商户号（需营业执照）；
网站收款要求支付域名 ICP 备案且主体与商户号一致；个体工商户不支持 H5 支付；
申请免费但费率 0.6%–1%，另加退款、发票、客服、税务负担。

## 决定

**保持免费，不接入任何支付渠道。**

- 想支持项目：用爱发电 / 赞赏码等第三方平台，资金不由本站处理。
- 不建套餐、计费、发票流程，也不为「将来收费」预留计费代码。

## 后果

- 成本由维护者承担 → 分析类接口必须有防滥用边界（缓存、限流、账号配额）。
- 「登录无限」不能覆盖高成本分析操作（具体配额到 API 阶段再定）。
- 若推翻此决定，新开 ADR。
