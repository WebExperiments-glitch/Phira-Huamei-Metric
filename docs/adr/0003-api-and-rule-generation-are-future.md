# ADR-0003：API 与规则写谱是方向，未排期

- **状态**：已接受（2026-10-17）

## 背景

维护者口述的未来方向：查询 + 分析 API（结果自动进缓存；匿名 100 次/小时，登录更高）；
CLI 与网页收敛；「规则写谱」作为独立产品线。**均未排期。**

## 决定

1. 不在当前代码里提前建 API 抽象；真有调用方时再开 ADR。
2. 留的最小边界：引擎纯计算、缓存读写走现有接口、错误模型逐步统一。
3. 规则写谱独立仓库/模块，不塞进 k-NN 引擎。
4. 任何人（包括 AI）看到本 ADR，**不得当成待办自动开工**。

## 后果

- 当前不承诺 API 兼容性。
- 需要 API 时先补：版本前缀、鉴权、配额、契约测试、OpenAPI。
