# ADR-0001：网页版是产品引擎，CLI 是研究工具

- **状态**：已接受（2026-10-17）

## 背景

仓库有两套难度引擎：

- `phm/core.py`：4 维 k-NN、1,037 张官谱参照，CLI 使用；
- `phm-web/public/js/engine.js`：8 维 k-NN、9,508 社区谱 + 1,037 官谱、双标度，网页/服务端使用。

两者数字不可互比，过去文档混着讲，容易被误读成「同一件事的两个实现」。

## 决定

1. **网页引擎是产品引擎**：线上、服务端复核、未来 API 都以 `engine.js` 为准。
2. **CLI 冻结为研究/复现工具**：不再新增功能，不承诺与网页数字一致，输出标 `cli-4d` 口径。
3. 差异只在 `ENGINE-EXPERIMENT.md` / `docs/结果/` 解释。

## 后果

- CLI 的 bug 只在研究结论受影响时修。
- 未来收敛优先走「CLI 变 API 客户端」，而不是重写 CLI 或复制引擎。
- 新文档必须写清讲的是哪套引擎。

## 被否掉的选项

- 现在用 Node 桥接让 CLI 直接调 `engine.js`：引入 Node 依赖，维护面更大；等 API 更划算。
- 立即合并两套引擎：校准数字会全变，风险高、收益低。
