# 非目标（Non-goals）

明确「不做什么」，比列「要做什么」更能防止膨胀。每条都对应一次真实取舍；改动需新开 ADR。

## 产品

- ❌ 不判定「虚标」：官方标注噪声 2.80 级，任何判定都是造假。
- ❌ 不做付费、不接支付（ADR-0002）。
- ❌ 暂不做 API / 规则写谱（ADR-0003，方向未排期）。
- ❌ 不做移动 App；Windows 客户端只是数据采集端。
- ❌ 不做多租户 / 团队协作 / SaaS 控制台。

## 技术

- ❌ 不引入前端框架/构建链（React、Vite、TS 编译）。
- ❌ 不引入 Node/Python 第三方运行时依赖（保持零依赖可跑）。
- ❌ 不为「未来 API」提前抽象；等调用方出现再设计。
- ❌ 不合并两套引擎（ADR-0001）；CLI 冻结。
- ❌ 不做实时协作 / 消息队列 / 微服务拆分。

## 数据

- ❌ 不上传谱面文件本身（只上传结构特征）。
- ❌ 不承诺「绝对安全」；只承诺写清边界并持续修补。
- ❌ 不把 31GB 原始语料塞进 git；只保留可重建真源。
