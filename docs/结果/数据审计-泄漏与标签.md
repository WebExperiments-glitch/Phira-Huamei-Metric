# 数据审计：泄漏与标签（2026-11-06）

> 两项审计同时做了，结论对我们过去所有报出的数字都有影响。

## ① 同谱重复：机制存在，但影响测不出来 → 该结论所用的数字已作废

### ⚠⚠ 第二次修正（2026-11-06 深夜）

本节两次用到的 v3/v4 数字**全部无效**，原因是我在
`tools/rerun_baselines_grouped.py` 里写了 `base[:, :142]`。

缓存是 **24 维 × 7 统计 + 2 = 170 维**，`[:142]` 实际切出的是
「24 个 mean + 24 个 std + 24 个 min + 24 个 max + 22 个 p10」——
**跨维度截断**，不是 20 维的池化向量。

实测（3 张谱，正确 142 维 vs 我的切片）：

```
10469  max|Δ|=988   相关=0.127
10475  max|Δ|=728   相关=0.205
10479  max|Δ|=297   相关=0.071
```

**基本不相关。** 所以 0.7984 / 0.8120 / 0.8176 / 0.8366 这四个数，
以及基于它们的「泄漏虚高 +0.0136 / +0.0190」全部作废。

### 仍然成立的结论

1. 同谱重复**机制上存在**（48 组 / 96 张，占 1.3%），分组切分应当保留（语义正确、免费）
2. 它对本数据的影响**测不出来** —— 但这一点现在只有"1.3% 太小"的推理支撑，
   没有可信的实测数字
3. 唯一可信的基线来自 `tools/train_seq_model.py`（它用的是正确的 142 维池化）：

```
分组切分，单 seed
  岭回归 142 维           ρ = 0.804
  岭回归 + 手型 256 维     ρ = 0.822   （+0.018）
  序列模型 + 手型          ρ = 0.845   （vs 岭+手型 +0.022，CI [+0.0095,+0.0364]）
```



## ② 五档通过率曲线的可学性：从 0.75 单调掉到 0.56

同一套特征（170 维）、同一套切分，换不同目标：

```
目标                     ρ
标量 b                  0.7135
曲线水平（五档均值）      0.6837
最低档 acc              0.7514   ← 最可学
低档 acc                0.6347
中档 acc                0.5876
高档 acc                0.5631
最高档 acc              0.5603   ← 最不可学
```

**这组数字说明我们的特征抓到了什么、没抓到什么：**

- 弱玩家打不过去，主要因为**物量负担**（音多、手要跨得远）→ 有特征，能预测
- 强玩家打不过去，是因为**技术要求**（反直觉键型、读谱、体力分配）→ 没特征，预测不了

## ③ 与前一个未解之谜对上了

早前诊断：**定数 16 以上的谱被系统性低估约 0.5 级**。

现在解释清楚了：高难度谱的难度**恰恰来自强玩家才感觉得到的东西**，
而我们对那一端的预测力只有 0.56。**所以高档谱必然被低估。**

这不是校准问题（等渗/分位数校准动不了它），是信息缺口。

## 结论

1. **短期**：所有历史 ρ 标注「含约 0.02 泄漏虚高」，新实验一律用分组切分
2. **中期**：标签端用五档曲线做辅助任务，重点是逼模型学「对强玩家也难」的部分
3. **长期**：要真正补上高档那一端，需要玩家侧的信息（回放、失手位置），
   单靠谱面几何拿不到——这条已被四次特征实验和 0.877 的残差相关反复证实
