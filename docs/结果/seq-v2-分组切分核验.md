# seq-v2 分组切分核验（2026-11-06 收尾）

## 结论：线上「精确计算」按钮成立，可以保留

```
分组切分、单 seed、15 epoch
  岭回归 142 维          ρ = 0.804
  岭回归 + 手型 256 维    ρ = 0.822
  序列模型 + 手型(seq-v2) ρ = 0.845
```

配对 bootstrap：

```
vs 岭回归 142 维      Δρ +0.0407  95%CI [+0.0234, +0.0595]  ✓
vs 岭回归 + 手型       Δρ +0.0222  95%CI [+0.0095, +0.0364]  ✓
```

两个 CI 下界都 > 0。**之前"顺序颠倒"的担心是错的**——
那一轮跑的序列模型没带手型，不是同一个模型。
