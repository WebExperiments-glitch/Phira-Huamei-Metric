# 残差诊断：真正的误差源在低难段，不在 17+

> 2026-11-26 · 链式 3 段之后的下一步调查
> 结论：**低难段（1–12）贡献 31% 的总误差，且系统性高估 +4.18。
> 但「加低段专家」失败，原因是混合机制依赖预测值，而预测值本身就是错的。**

---

## 一、为什么要做这个诊断

3 段链式已经把 17+ 从 0.9598 压到 0.6996。下一步要「再加一个专家」之前，
必须先回答：**这个专家该按什么分？**

凭直觉定「密集型 / 位移型 / 多线型」可能切出没有实际差异的组，
所以先量：**沿哪个维度，误差有系统性结构**。

---

## 二、分档绝对 MAE（这才是真相）

基线单模型，5 折 GroupKFold by charter，9,504 张：

| 段 | n | MAE | 中位 | 占总误差 |
|---|---:|---:|---:|---:|
| **1–10** | 219 | **5.928** | 5.175 | **16.6%** |
| **10–12** | 341 | **3.315** | 3.086 | **14.4%** |
| 12–14 | 1,266 | 0.722 | 0.555 | 11.7% |
| 14–15.5 | 3,702 | 0.533 | 0.415 | 25.2% |
| 15.5–17 | 3,060 | 0.535 | 0.417 | 20.9% |
| 17–18 | 619 | 0.742 | 0.618 | 5.9% |
| 18–21 | 297 | 1.413 | 1.100 | 5.4% |

### 这张表推翻了之前的注意力分配

- **1–12 只有 560 张（5.9%），却贡献 31% 的总误差**
- 我们之前一直在优化的 17+（916 张），只贡献 11.3%

**全区间 MAE 0.8243，其中三分之一来自 5.9% 的低难谱。**

### 偏差方向

| 段 | 偏差（正=高估） |
|---|---:|
| 1–12 | **+4.158** |
| 12–14 | +0.188 |
| 14–15.5 | −0.159 |
| 15.5–17 | −0.387 |
| 17–21 | −0.887 |

**低难段严重高估，高难段轻低估** —— 模型把整个难度轴压扁了。

## 三、误差最大的那 5% 是什么谱

阈值 |err| ≥ 2.731，n=476。它们的特征（相对全体）：

| 特征 | 倍数 |
|---|---:|
| `ranked` | **0.10x**（几乎全是未上架谱） |
| `weighted_mf_score_per_sec` | **8.37x** |
| `stable` | 0.16x |
| `strain_raw_max` | 4.07x |
| `strain_p99` | 2.59x |
| `bpm` | 2.08x |
| `t_drag` | 1.76x |
| `drag_per_sec` | 1.72x |
| `duration` | 0.63x |

画像：**短、BPM 极高、多指密集、strain 爆表、大量 drag、未上架**，
但实际定数很低 —— 典型的「物量整活谱」。

模型学到的规律是「物量高 → 难度高」，对这类谱完全失效，于是
**预测成 12+，实际是 6–9，误差 5 个量级**。

---

## 四、是模型问题还是标签问题？

按 ranked（Phira 认证）拆分：

| 段 | ranked MAE | 非 ranked MAE | ranked 偏差 | 非 ranked 偏差 |
|---|---|---|---:|---:|
| 1–12 | 2.658（n=8） | **4.361**（n=552） | +2.66 | **+4.18** |
| 12–14 | 0.666（n=62） | 0.725（n=1,204） | +0.35 | +0.18 |
| 14–15.5 | 0.397（n=294） | 0.545（n=3,408） | +0.09 | −0.18 |
| 15.5–17 | 0.461（n=198） | 0.540（n=2,862） | −0.30 | −0.39 |
| 17–21 | 0.789（n=17） | 0.963（n=899） | −0.69 | −0.89 |

**两边都高估**（ranked +2.66 / 非 ranked +4.18），说明**不只是标签噪声**。
但 ranked 样本只有 8 张，不足以定论；非 ranked 更严重也是事实。

**最可能的解释**：低难谱在训练集里只占 5.9%，且特征分布与主流差异极大。
模型对它们实际上是**外推**，而外推方向被「物量→难度」的强先验带偏。

## 五、加低段专家的尝试（失败）

设计：标签 `< 12` 的样本单独训一个专家，预测值低时接管。

结果：

| | 全区间 MAE | 1–12 ΔMAE | 12–14 ΔMAE |
|---|---:|---:|---:|
| 3 段（14/17） | **0.7885** | — | — |
| **3 段 + 低段专家** | 0.8231 | +0.0064 | **+0.3352** |

**全区间退步，12–14 段大幅退步（+0.335），1–12 段几乎没改善。**

### 为什么失败 —— 这是本次最重要的机制发现

混合权重按**预测值**算：

```python
w = 1 - clip((pred - (12 - 0.5)) / 1.0, 0, 1)
```

但模型对低难谱**系统性高估 +4.16**：

> 真实 8 分的谱 → 模型预测 12.2 → `pred > 11.5` → **低段专家权重为 0**
> 需要它的样本，恰好不在它的覆盖范围内。

**按预测值门控，在高估严重的区间会自我失效。** 这是链式结构的边界条件，
不是实现 bug。

## 六、结论与建议

### 6.1 3 段链式（14 / 17）仍是最优结构

- 全区间 0.8245 → 0.7885
- 17+ 0.9598 → 0.6996
- 加低段专家会让全区间退回 0.8231

### 6.2 低难段的误差，我建议「承认而不修」

理由三条：

1. **样本稀缺**：1–12 只有 560 张（5.9%），撑不起一个稳定专家
2. **标签可疑**：ranked 只有 8 张、非 ranked 偏差 +4.18，无法区分「模型错」与「标签错」
3. **不是主战场**：Phira 生态里 <12 的谱几乎没人玩，定数标注本身随意

**更诚实的做法是展示层标注**：当引擎输出 < 12 时，明确告诉用户
「低难段预测不可靠（训练样本仅 5.9%）」，而不是假装它准。

### 6.3 如果要修，唯一可行的方向是「按特征门控」

不用预测值，改用**特征**判断该由谁负责：

- 差组的标志是「高 BPM + 高多指 + 高 strain + 短时长」
- 可以训一个小的二分类器：`是否属于物量整活谱`
- 由它决定是否启用低段专家

但这已经超出「链式专家」的范畴，是真正的 MoE gating。
**需要先有更多低难谱样本，否则门控本身也会过拟合。**

## 七、这次诊断的方法论收获

| 之前以为 | 实际 |
|---|---|
| 误差大头在 17+（难，所以错） | **在 1–12（样本少 + 特征冲突）** |
| 天花板由高难段决定 | 天花板被低难段的 5.9% 拖住 |

**「哪里难」和「哪里错得多」是两件事。** 前者靠直觉，后者只能靠量。

如果不做这次诊断，下一个专家会加错地方 —— 而且加了之后
全区间指标还会退步（就像刚才那次）。
