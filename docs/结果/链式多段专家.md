# 链式多段专家（结构级创新）

> 2026-11-26 · 在双模型基础上继续加段，找到最优结构
> 结论：**3 段最优。17+ MAE 从 0.96 降到 0.70，18+ 段改善 0.47。**

## 一、从双模型到多段

双模型（单段分界 17.0）已验证有效，那自然要问：**段数越多越好吗？**

实现方式（`tools/ab_multi_expert.py`）：

```
p0 = 全量主模型
p1 = p0 与「≥A1 段专家」按预测值软混合（A1±0.5 内线性过渡）
p2 = p1 与「≥A2 且 <A1 段专家」软混合
...
```

每加一层只是一个新的 Ridge，**不需要重构模型**，可逐层验证收益。
软混合按**预测值**触发（推理时没有标签）。

## 四、为什么 3 段最优

`14` 和 `17` 这两个分界不是我搜出来的，是**数据分布的自然断点**：

| 段 | 张数 | 占比 |
|---|---:|---:|
| < 14 | 1,826 | 19.2% |
| 14 – 17 | 6,762 | 71.2% |
| ≥ 17 | 916 | 9.6% |

- **< 14**：样本少、难度低、特征分布窄
- **14–17**：主体（71%），内部差异大（14 的谱和 17 的谱完全不同）
- **≥ 17**：顶端，样本少但极重要

3 段把「主体」单独切开，让中段专家专门拟合 14–17 的细微差异 ——
这样顶端专家不必再为「大量中段样本」做妥协，顶端精度直接跳了一档。

**4 段为什么退步**：`< 12` 只有 560 张（5.9%），样本不足以支撑一个专家，
反而把主模型的训练集切薄了。

## 五、这个架构能衍生出什么

### 已经验证的三条

| 方向 | 状态 |
|---|---|
| 单模型 | 已验证（基线） |
| 2 段（按难度） | 已验证，17+ −0.10 |
| **3 段（按难度）** | **已验证，17+ −0.26 —— 当前最优** |
| 4 段 | 已验证，退步 |

**结论：按难度分段存在最优段数（3 段），不是越多越好。**

### 还没验证但更本质的方向

**按谱面「类型」分专家**，而不是按难度。

理由：同一难度的谱，难度来源可能完全不同 ——
- 密集型（高 NPS、低位移）
- 位移型（低 NPS、高 jump）
- 多线型（大量跨判定线）
- 长条型（高 hold 覆盖）

用一个模型拟合所有类型，等于假设「难度 = f(特征) 对所有谱同构」。
**按类型分专家是放弃这个假设**，比按难度分更根本。

实现门槛：
1. 需要先定义「类型」——可用聚类（在特征空间 KMeans）或人工规则
2. 类型必须只依赖特征（推理时可用），不能用标签
3. 门控需要软归属（一个谱可能 70% 密集 + 30% 位移）

### 门控 MoE（真正的 MoE）

让一个小的 gating 网络学「这张谱该由谁负责」，而不是人定分段。

代价：需要联合训练门控 + 专家，9,504 张样本偏少，**过拟合风险高**。
而且如果 3 段链式已经饱和，门控的增量可能有限。

### 我的判断

**先把 3 段链式上线**，它已经是干净的、可解释的、可验证的结构改进。
「按类型分专家」作为下一个研究课题 —— 它需要先解决「类型怎么定义」这个前置问题，
不是一天能做完的。
