# 模型定案：岭回归 vs SSM（LNN 的可并行形态）

> 2026-11-02。**结论：生产用岭回归，SSM 只作为研究上限保留，不再投入。**

---

## 一、逐项对比（同一份数据 V0.1-beta.2 · 20 维 · 7,504 张）

| 项 | 岭回归 | SSM | 谁赢 |
|---|---|---|---|
| ρ（T1 随机） | 0.8024 [0.775, 0.829] | **0.8162** [0.790, 0.839] | SSM +0.014 |
| **配对检验** | — | **95% CI [−0.023, +0.051]，跨 0** | **平手** |
| MAE | 0.441 | 0.440 | 平手 |
| 参数量 | **142 个权重** | 69,187 | 岭回归 487 倍小 |
| 单谱延迟（CPU） | **3.17 ms** | 234 ms | 岭回归快 **74 倍** |
| 权重体积 | < 100 KB | 275 KB | 岭回归 |
| 可解释 | ✅ 每个特征一个权重 | ❌ | 岭回归 |
| 浏览器内运行 | ✅ 纯算术 | ❌ 需 PyTorch/ONNX | 岭回归 |
| 训练成本 | **秒级** | 2 小时 / 组切分 | 岭回归 |

**除 ρ 高 0.014（噪声内）之外，岭回归在所有维度上更好，其中三项是数量级差距。**

## 二、为什么会出现这个结果

特征与架构是**替代品**：

```
10 维时：SSM 0.8124  vs  岭回归 0.7353   → +0.077（显著）
20 维时：SSM 0.8162  vs  岭回归 0.8024   → +0.014（不显著）
```

序列模型的优势来自"能自己从序列里推出移动距离、夹角、跳跃速度"。
这些一旦被显式写进特征，线性模型立刻追平。

**推论：继续换架构不会带来新信息，只会继续消耗时间。**

## 三、定案

```
生产模型  岭回归（142 权重）
          · 站内推理：浏览器内纯算术，零依赖
          · 服务端 API：微秒级
评估口径  tools/bench_v1.py 的 T1–T8，宏平均 + 每项 CI
研究上限  SSM（69k，ρ 0.8162）
          · 只在天花板需要更新时才重训，不作为候选上线
          · 权重存档 release/phm-difficulty-ssm/
下界锚点  count_only（宏平均 0.4176）—— 永不删，用来羞辱无效模型
```

## 四、当前八项成绩（岭回归，公开集）

|---|---|---|

| T2 换谱师 | 0.789 | **没有谱师泄漏** |

宏平均 **0.7529**（vs 只数音符 0.4176）。

## 五、什么情况下要推翻这个定案

1. 岭回归在某个任务上明显塌（例如 T6 < 0.5），而 SSM 不塌 → 值得为那个场景单独上 SSM
2. 特征数量继续增长到 100+ 维，线性模型开始欠拟合 → 换非线性（先试核岭回归，不试深度模型）
3. 标签口径变化（例如改用"通关率"而非 b）→ 全部重测

**在以上任一条发生之前，不要再开架构实验。**
