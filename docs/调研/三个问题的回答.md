# 三个问题的直接回答

> 2026-10-05 · 含对前几轮结论的修正

---

## 问题一：这个公式真的能用吗？

**能用，但只能在特定场景，而且必须带置信度输出。**

### 能做的

| 场景 | 可行性 | 依据 |
|---|---|---|
| 给出难度**参考区间** | ✅ 89.7% 落在 ±1.5 级 | 官谱 LOO 实测 |
| 识别**明显异常**（差 2.5 级以上） | ✅ | high 档 p90 = 1.5 |
| 解释「**为什么难**」 | ✅ | 18 维偏相关已量化 |
| 区分**谱型**（抽象/假键流/高难） | ✅ | 已验证有效 |
| 帮助谱师理解**差在哪** | ✅ | 各维度分位可展示 |

### 做不到的

| 场景 | 原因 |
|---|---|
| 精确定数（±0.5 级） | 只 45.5%，**不可靠** |
| 判定「虚标」定性 | 官方标注本身有 2.8 级噪声，无法区分 |
| 用差值当「虚标证据」 | ❌ **绝对不行** —— 会误伤合规谱 |

### 我最看重的一点

**公式的误差（p90=1.55）小于官方标注自身的离散度（p90=2.00）。**

这意味着：我们的公式比官方自己「更一致」。这不是夸口，是实测。

**所以最诚实的定位是**：

> 这是一个**参考工具**，不是**裁判工具**。
> 它能告诉你「这张谱在同类中处于什么位置」，
> 但不能告诉你「你定错了」。

## 问题二：对 18 维怎么看？

**做对了工程，错了假设。**

### 做对的

1. **算法全部逐行对照竞品源码实现**（`feature_extractor.py` 2190 行）
   - 有效单指密度（同押去冗余）这个设计很精妙
   - 高潮段用**区间并集**而非窗口计数
   - 判定线演出的**事件计数**口径

2. **发现并修正了自己的两个 bug**
   - 判定线密度算成「时长/秒」，应为「事件计数/秒」
   - 高潮段判定条件写错

3. **建立了可解释特征库**，18 维每维都有明确物理含义

### 错的假设

我以为「维度越多越准」。实测证明**完全相反**：

```
v2 基线（2 维）   MAE 0.700
+ 4 维            MAE 0.800
+ 6 维            MAE 0.900
+ 11 维           MAE 1.300
```

**根因：要素信号（偏相关 0.12~0.52）远小于官方标注噪声（2.80）。**

在 1,037 条样本上细化到 0.12 量级的偏相关，就是在拟合噪声。

### 18 维的正确用途

**不用于定价，用于解释。**

> 该谱公式参考值 14.8，标注 15.3。
> NPS 偏上 60%，纵连速度偏上 20%（+0.52 强正向），
> 长押干扰偏下 35%（−0.47 强负向）——
> 两者抵消，故公式略低于标注。

**这比只给一个数字有用得多。** 谱师能看到「差在哪」，而不是被告知「你错了」。

## 问题三：Phira 制谱师是纯凭主观吗？

**我用数据做了检验。答案分两层，且其中一层对我不利。**

### 检验一：官方公式能否预测社区谱定数？

```
用官谱公式预测社区谱（n=9,512）
  |误差| 中位 0.80   p90 4.30
  ≤1.0 占 58.8%   ≤2.0 占 79.9%

对照：社区谱定数标准差 = 2.12
```

**误差中位 0.80 vs 标准差 2.12 → 误差只有标准差的 38%。**

✅ **社区谱定数有规律，不是乱填的。**

如果纯随机，误差应该等于标准差（2.12），实测只有 0.80。

**79.9% 的谱落在公式 ±2.0 级内。** 这不可能是巧合。

### 检验二：各特征的相关性对比

| 特征 | 官谱 r | 社区谱 r |
|---|---|---|
| NPS | +0.8742 | +0.3345 |
| 物量 | +0.8455 | +0.2655 |
| 快速音符% | +0.7500 | +0.4412 |

**社区谱的相关性方向一致，但强度只有官谱的 1/3。**

**含义**：社区谱师**参照了**与官方类似的逻辑（NPS/物量确实影响定数），
但**执行得不那么严格**。

### ⚠️ 检验三：这是我必须承认的负面证据

**同曲相邻难度定数递增率只有 68%**（官谱是 100%）。

```
官谱：327 首全部递增，0 例外
社区谱：25 组里 17 组递增，8 组递减（32% 递减）
```

**这说明社区谱的定数一致性明显不如官谱。**

如果谱师都遵循「同一个 IN 一定比 HD 难」这个原则，递增率应该接近 100%。
实测 68% → **有三分之一的同曲难度是「倒挂」的。**

### 综合结论

| 层级 | 判断 |
|---|---|
| **不是纯随机** | ✅ 公式能预测 80%（±2级内） |
| **有内在标准** | ✅ 与官方逻辑同向 |
| **但执行不严格** | ❌ 32% 同曲难度倒挂 |
| **一致性明显低于官方** | ❌ 官谱 100% vs 社区 68% |

**所以答案是**：

> Phira 谱师**不是纯凭感觉**，但也**没有遵循统一标准**。
> 他们各自有一套「心里有数」的经验，
> 但这套经验从未被写成规则，所以无法互相校验、无法传承。

**这正是本项目的价值点**：
不是「我来定标准」（没人会听），
而是「把大家心里那套隐性标准量化出来，让谱师能自己对自己对答案」。

## 最后：一个诚实的自我修正

前面几轮我犯了一个错误：**把「官谱定数」当成了「客观真值」**。

实际上官谱定数也是人工标注的，噪声 2.80 级。
我基于它训练公式，再宣称公式能「判定虚标」——**逻辑上站不住**。

**修正后的定位**：

| 能说 | 不能说 |
|---|---|
| 「按官方谱型统计，这个谱的参考值是 14.8」 | 「这张谱虚标了 0.5」 |
| 「这张谱落在同物量同难度的正常区间外」 | 「这张谱的定数是错的」 |
| 「它的纵连密度异常高，可能偏易」 | 「创作者在虚标」 |
| 「这 260 张定数超官方历史上限 18.0」 | —— 这条是硬事实，可以说 |

**最后那条例外**是唯一能确定说的——
因为它不依赖任何模型，只依赖「官方 1,037 条定数的最大值」这个客观事实。
