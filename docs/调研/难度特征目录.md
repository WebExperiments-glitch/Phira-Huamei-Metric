# 谱面难度特征目录（对照 osu! / PhiraiAd / 我们的进度）

> 2026-11-02。回答一个问题：**到底有多少可用特征，我们还差多少？**
>
> 素材来源：
> - **osu!** 的 skillset 模型（Aim / Speed / Reading / Flashlight）+ strain 累积 + 三连音 Angle + 25ms 最小跳跃时间
> - **PhiraiAd**（GPL-3.0，`phira/src/ai_model/features.rs`）：17 事件维 + 6 同刻组维 + 18 整谱统计
> - **Etterna MinaCalc**（4K 领域的事实标准，技能维度：stream / jumpstream / handstream / stamina / jackspeed / chordjack / technical）
>
> 结论先行：**我们现在 20 维，PhiraiAd 41 维（17+6+18），osu! 光预处理就有 7 个对象级量。**
> 但维数不等于信息 —— 关键是位置对不对。

## 二、我们有、它们没有（差异化）

| 特征 | 为什么重要 |
|---|---|
| 同侧连续标志 | 双指谱里"连续打同一只手"是主要体力来源，PhiraiAd 按 side 分组但不显式建模连续 |
| 相对时间（log） | 长谱末段的状态应与开头不同 |

## 三、它们有、我们还没有（按性价比排序）

### P0 · 判定线运动后的真实坐标 ★★★★★

```
我们现在：x = note.positionX（谱面坐标系）
应该是：  point = line.point(tick, x)（判定线移动/旋转后的屏幕坐标）
```

**这是我们最大的盲点。** 谱面可以把判定线移走、旋转 90 度——此时 `positionX` 相同的两个音符，
在屏幕上可能相距很远。移动距离、夹角、跳跃速度**全都建立在错误坐标上**。

需要扩展 `chart_io` 读 `judgeLineMoveEvents`（start/end + start2/end2，二阶缓动）与
`judgeLineRotateEvents`。

### P0 · 长条覆盖与重叠 ★★★★

```
coverage = 有长条按住的时长 / 总时长
overlap  = 同时有 >1 个长条按住的时长 / 总时长
```

长条按住期间还要打普通音符 → 多任务负载。这是难度里实打实的一块。

### P1 · 整谱峰值统计 ★★★★

```
1 秒窗口最大按键密度（峰值）      ← PhiraiAd 的核心统计之一
p90 密度
最大和弦、和弦比例
中位/最小间隔、>1s 空档占比
```

我们靠池化从事件特征推导，但**池化用的是均值/分位，抓不到"1 秒窗口"这种时间局部量**。

### P1 · 流速与判定线流速 ★★★

`log(speed)`、`log(line_speed)`。流速影响读谱窗口：同样密度的谱，流速快时要更早读。

### P2 · 音符朝向角 ★★★

PhiraiAd 的 `angle = rotation - 90°·side + (speed<0 ? 180° : 0)`，取 sin/cos。
它把"音符在屏幕上的方向"编码进去，这影响视觉处理成本。

### P2 · 双押/多押的时间结构 ★★★

不是"同时几个键"，而是**多押出现的节奏规律**：
连续同间隔多押（可背）vs 随机出现（难读）。

### P3 · 模式重复度（我们的原创想法）★★

整谱的间隔序列有多少重复子串。**重复多 = 可记忆 = 相对简单**。
MinaCalc 的 `technical` 维度就是这个思路：难的不是速度，是"没有规律可循"。

## 四、维度规划

```
beta.2  （现在）  20 维 · 位置/移动/夹角/和弦/密度/strain
beta.3            +判定线运动与旋转的真实坐标（重写 chart_io）  → 最影响结果
beta.4            +长条覆盖/重叠、峰值统计（1s 窗口）
beta.5            +流速、音符朝向、模式重复度
```

每加一批都单独记一次 ρ —— **一次只动一个变量**，否则又变成"调了一堆不知道哪个起作用"。

---

## 五、一个提醒

PhiraiAd 的 41 维比我们多，但它的目标是**逼近定数**；我们的标签是**玩家实测 b**。
两个标签之间的 ρ 只有 0.68 —— 也就是说，**就算我们把 41 维全抄过来，
对 b 的预测也未必能超过 0.75**，因为 b 里有一部分是"定数表达不了的东西"。

这一条既是风险，也是我们的独特价值：**我们能测出定数测不到的那部分。**
