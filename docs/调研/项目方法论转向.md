# 定数是主观的，那这个项目怎么做？

> 2026-10-05 · 核心方法论转向

---

## 一、先纠正一个前提

你说「我原本以为很简单」。

**你的判断没错，只是差一层。**

| 你以为的问题 | 真正的问题 |
|---|---|
| 「定数是客观的 → 算出来就行」 | 「**没人知道该怎么算**」 |
| 技术问题 | **信息问题** |

如果定数有官方公式，Phigros 早就公开了（它公开了判定窗口、rks 公式、Data 分档）。
**没有公式本身就是最大的信息。**

---

## 二、主观 ≠ 不可分析

### 2.1 主观也有结构

我刚测出一个关键证据：

```
社区谱定数取值分布
  15.0   694 张  (7.3%)
  14.0   520 张  (5.5%)
  16.0   400 张  (4.2%)
  13.0   247 张  (2.6%)
  15.4   178 张  (1.9%)
  15.6   178 张  (1.9%)
  15.7   161 张  (1.7%)
  15.8   159 张  (1.7%)
```

**整数（15.0）比一位小数（15.4）常用 3.9 倍。**

这是典型的「拖滑块」指纹——
编辑器里 `difficulty` 是一个 **0~20 步进 0.1 的 f32 滑块**
（我已从 Phira 源码 `chart_info.rs:107` 核实）。

**这说明什么**：

> 定数的 0.1 精度是**机械精度**（滑块最小刻度），
> 不是**语义精度**（真正的难度分辨率）。

官方大概率是「拖到 15.3」，不是「算到 15.3」。

**这就是「主观」的具体形态** —— 主观不等于随便，
而是「基于感觉 + 参考同类 + 拖到滑块刻度」。

### 2.2 主观也能被量化到有用的程度

我实测过：

| 检验 | 结果 | 含义 |
|---|---|---|
| 官谱公式预测社区谱 | 误差中位 **0.80** vs 标准差 2.12 | **不是乱填的** |
| 79.9% 落在 ±2.0 级内 | — | 有稳定规律 |
| 特征相关性方向 | 与官谱**同向**，强度 1/3 | 参照了官方逻辑 |

**所以准确的说法是**：

> 定数是「**有内在逻辑的主观**」——
> 谱师心里有一套标准，但从未写成规则。

## 三、所以项目怎么做：从「裁判」转为「显影」

### 3.1 原来想做的（错）

```
❌ 我来算出定数 → 不符就判虚标
```

**必然失败**：
- 我的噪声 2.80 级 = 官方噪声 2.80 级
- 谁都判不了谁

### 3.2 应该做的（对）

```
✅ 把谱师「心里有数」的那套标准显影出来
```

**核心洞察**：

> 如果「IN 15.3」这个数字是拖出来的，
> 那让谱师互相校对这个数字就毫无意义。
>
> **但让谱师互相校对「谱面到底难不难」是有意义的。**

**区别在哪**：
- 定数：一个人拖的，拖到 15.3（可能是 14.8 的手感，也可能是 16.0）
- 难度参考区间：算出来的，[14.3, 15.8]（可复核、可争论）

## 四、具体的产品形态

### 4.1 核心功能：差异对照

不给分数，**给「你和同类的差距」**。

```
你的谱：千本樱 S
─────────────────────────
你的特征：
  NPS 6.2  → 同 IN 中位，偏高 20%
  物量 1240 → 同 IN 中位，偏高 35%
  Hold% 18  → 同 IN 中位，偏低
  纵连速度 3.2 → 同 IN 中位，偏低 60%
  难度标签 IN Lv.15

参考区间：[14.6, 15.9]（同类中位 ±0.7）

⚠️ 你的物量偏高但手速与配置复杂度偏低
   → 参考值偏下限
   → 若你填 16.0+，可能偏高
```

**这个说法有四个优势**：
1. 不说「你错了」，说「同类通常是这样」
2. 给出依据（哪个特征偏了），可争论
3. 任何人都能自己跑公式验证
4. **不需要「什么算虚标」这个无法定义的问题**

### 4.2 次要功能：一致性检查（这是硬判据）

不需要模型的、不依赖主观的检查：

| 检查 | 依据 | 性质 |
|---|---|---|
| **定数 > 18.0** | 官方 1,037 条无一超过 | **硬事实** |
| **同曲难度倒挂** | 官谱 0 例外，社区 32% | 统计异常 |
| **同物量同难度离群 > 3σ** | 社区自身分布 | 统计异常 |
| **Liveness 冲突** | phira.moe 前端同款规则 | 硬规则 |

**这四条不依赖任何模型，纯客观。** 可以理直气壮地说。

### 4.3 附加功能：官方谱型参照

「你的谱和官谱里哪些谱特征相似」——
让谱师从官谱的 1,037 个定价案例里找参照。

```
与你的谱最相似的官谱：
  Stasis [IN 15.6]   NPS 6.4  物量 1310  Hold% 16  纵连 2.1
  Cronostasis [IN 15.5]  NPS 6.1  物量 1195  Hold% 19  纵连 2.4
→ 这两首官谱定价 15.5~15.6
```

**这个功能完全客观**：相似度可复现，参照谱可查证。

## 五、为什么这仍然是个有价值的产品

### 5.1 解决真实痛点

社区现在的问题：
- 定数无标准 → **无法互相校对**
- 谱师只能问「你们觉得这谱难吗」
- 得到的回答是模糊的

**显影工具给的是可复核的答案**。

### 5.2 我们的独特位置

| | 竞品 | 我们 |
|---|---|---|
| 输出 | 一个预测数字 | 区间 + 特征差异 + 可复核公式 |
| 可审计 | 333 特征 + 56 权重 | 2 维度 + 每个格子可追溯到官谱 |
| 定位 | 「我算出你的定数」 | 「你和同类的差距在哪」 |
| 争议时 | 「我的模型更准」（无法验证） | 「你跑一遍就知道」（可验证） |

### 5.3 长期价值

数据在积累：
- 现在 1,037 条官谱 → 噪声 2.80 级
- 若官谱样本增到 5,000+ → 噪声降低，区间收窄
- 社区谱标注也在积累

**我们做的不是一个工具，是一套「难度描述语言」。**

## 六、结论

### 原来以为的困境 → 实际的机会

| 困境 | 机会 |
|---|---|
| 定数是主观的 | 所以**需要**一个客观参照 |
| 没有官方公式 | 所以**有空位** |
| 判不了「虚标」 | 所以**该做诊断而非审判** |
| 噪声 2.80 级 | 所以**该给区间不给点** |

### 唯一的技术前提

**公式必须 100% 可审计、可复现。**

这是竞品做不到的（GB 树 333 特征），
也是我们唯一能站住的地方。

---

## 七、下一步（很明确）

1. **把公式套到社区谱**，但输出格式是「参考区间 + 特征差异」而非单一数字
2. **加四条硬判据**（定数>18.0 / 同曲倒挂 / 离群3σ / Liveness 冲突）
3. **加官谱参照功能**（找最相似的官谱）
4. **GUI 化** —— 让谱师拖进自己的谱就能看

**这套东西谱师会真的用。** 因为它解决的是一个真实存在、且目前无解的问题。
