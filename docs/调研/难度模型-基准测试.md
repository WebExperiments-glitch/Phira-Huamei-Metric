# 难度模型基准测试：为什么只报一个 ρ 不够

> 2026-11-01。起因：前面所有实验都只用「随机切分 + Spearman ρ」判好坏。
> 这个指标能被四种方式骗过，而我们一次都没防过。

---

## 1. 一个数字能骗过我们的四种方式

| 失败模式 | 表现 | 我们现在能发现吗 |
|---|---|---|
| **谱师泄漏** | 同一谱师的谱面同时出现在训练和测试里，模型记住的是"这个人的风格"而不是"这张谱有多难" | ❌ 随机切分会大量泄漏 |
| **时间泄漏** | 用 2025 年的谱面训练去预测 2023 年的谱面 —— 而产品里永远是**预测新谱** | ❌ 没有按时间切分 |
| **捷径学习** | 模型其实只学会了"音符多就难"。物量相关性本身就有 0.6+ | ❌ 没有"只给物量"的对照基线 |
| **分布外崩溃** | 长谱、短谱、冷门谱上完全失效，但平均值看不出来 | ❌ 只报总 ρ |

所以基准要做的不是"再多跑几个模型"，而是**造出让模型露馅的测试**。

---

## 2. 六组切分（S1–S6）

| 组 | 切分方式 | 抓什么 | 为什么难 |
|---|---|---|---|
| **S1 random** | 85/15 随机 | 对照组，与历史数字可比 | 不难，但它就是"泄漏版" |
| **S2 by_uploader** | 按谱师 uid 分组，15% 的谱师整组留出 | 谱师泄漏 | 模型必须泛化到**没见过的作者** |
| **S3 temporal** | 按上传时间，最早 85% 训练 / 最新 15% 测试 | 时间泄漏 | 谱面写法在演进，旧数据学不到新风格 |
| **S4 cold** | 训练 = 玩家 ≥200 的谱；测试 = **50–99 人**的谱 | 冷启动 | 产品里新谱就是这样：有人玩但不多 |
| **S5 long** | 测试 = 事件数 top 10% | 长谱外推 | 上下文/显存压力，且长谱往往是高难 |
| **S6 short** | 测试 = 事件数 bottom 10% | 短谱外推 | 信息少，最容易被当成"简单" |

## 3. 八项指标（S7 起是"非准确率"维度）

```
回归质量   ρ(Spearman) · τ(Kendall) · MAE · RMSE · R²
分档判别   ±0.5 档准确率 · ±1 档准确率     ← 产品真正需要的粒度
偏差       bias（系统性高估/低估）
```

## 4. 两个必跑的基线（S8–S9）

**S8 物量基线**：只用「音符数」一个变量做线性回归。
> 如果复杂模型打不过它，说明模型学到的全是"多就是难"。这是最便宜、最羞辱人的对照。

**S9 消融**：把输入列逐个置零/打乱，看 ρ 掉多少。
> 重点看 `dt`（第 0 维）：如果打乱时间间隔 ρ 不掉，那"时间感知"就是自我感动 ——
> 无论架构叫 CfC 还是 S6。

## 5. 判据

| 结论 | 条件 |
|---|---|
| 真有用 | S2/S3/S4 上都不比 S1 低 0.05 以上，且 > 物量基线 0.10 以上 |
| 只会数音符 | 与物量基线差距 < 0.03 |
| 会背谱师 | S1 高、S2 掉 >0.08 |
| 过拟合旧数据 | S1 高、S3 掉 >0.08 |
| 长尾崩 | S5/S6 掉 >0.10 |

## 6. 实现

```
tools/bench_suite.py       统一入口（切分 / 指标 / 模型注册表）
  prep      构建元数据索引（id → b, players, uploader, created, n_events）
  split     生成六组切分，缓存到 data/bench/splits.json
  run       对指定模型跑全部切分，输出表格 + JSON
```

模型实现统一接口：

```python
class Model:
    name = "..."
    def fit(self, ids_tr, y_tr): ...
    def predict(self, ids_te) -> np.ndarray: ...
```

⚠ **所有模型必须共用同一份切分与同一份输入缓存**，否则基准本身就不可比。
